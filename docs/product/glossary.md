# 术语表

| 术语     | 英文                   | 含义                                              |
| -------- | ---------------------- | ------------------------------------------------- |
| 家长     | Parent                 | 用邮箱注册，关联并查看自己孩子学习的角色          |
| 儿童     | Child                  | 有独立学习记录的学习者                            |
| 注册 KEY | Registration key       | 家长提供的关联凭据；不默认兼作长期登录密码        |
| 题目     | Problem                | 有稳定标识、分类及专属教学页面的硬编码学习内容    |
| 教学步骤 | Teaching step          | 当前需要理解或完成的一个小目标                    |
| 提示阶梯 | Hint ladder            | 从小提示到示范的逐级帮助；具体策略待确认          |
| 独立完成 | Independent completion | 在明确记录的条件下未依赖提示完成；不等同于已掌握  |
| 引导教学 | Guided teaching        | 使用题目预设交互、提示及规则，AI 不可用时仍能进行 |
| 掌握     | Mastery                | 可迁移到相似问题的独立理解；判断规则待确认        |
