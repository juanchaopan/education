# 产品愿景（草案）

## 一句话

为儿童提供中文交互式解题教学，通过说话、画图和逐步反馈培养独立理解，让家长了解孩子的学习进展。

## 目标用户

| 角色                       | 需要                                                               |
| -------------------------- | ------------------------------------------------------------------ |
| 儿童                       | 友好、耐心、可反复听讲的教学；知道哪一步出了问题以及下一步如何尝试 |
| 家长                       | 先用邮箱注册，再通过 KEY 关联孩子；查看各孩子的学习进度            |
| 内容维护者（用户与开发者） | 用户后续提供题目，开发者设计每题教学方式并实现专属页面             |

## 成功标准

- 用户确认的学习目标：孩子在相似题目上需要的提示逐渐减少，能够独立解题。
- 记录独立完成与提示后完成，避免把完成次数等同于理解程度。具体掌握判定待确认。
- 验证三个孩子同时学习的试点流程，以及 AI 不可用时仍可继续的引导教学。
- 性能指标和学习效果的量化门槛尚未确认，不将其视为已验证结果。

## 第一版范围

- 中文界面，框架不限定具体年级或学科；题目按年级、学科、分类、顺序组织。
- 家长邮箱注册；儿童通过家长提供的 KEY 自助注册并关联家长。
- 每人独立保存学习进度；家长查看自己孩子的进展。
- 支持开放式中文对话、绘图及相应反馈；优先研究免费且快速的方案。
- AI 失败、变慢或达到额度时，保存当前作答，继续题目专属提示及规则检查。
- 每题专属教学页面与共享框架结合；真实题目由用户之后提供。
- 手机、平板常见中文浏览器与桌面浏览器。具体浏览器版本需要验证；未将微信内置浏览器列为必需。

## 教学建议（待细化）

每次一个简短指令，允许反复播放与重试；先给小提示，再给示范，最后让孩子重新尝试。指出具体步骤或图形中的问题，避免责备和只报“错误”。对识别不确定的输入先请孩子确认，不能把识别失败算成知识错误。通过相似题或迁移步骤验证独立理解；缺少相似题时不宣称已经掌握。

## 约束

| 项目     | 约束与来源                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------------ |
| 规模     | 用户确认：私有试点，最多 10 个家庭，约 3 个儿童同时学习                                                |
| 语言     | 用户确认：仅中文                                                                                       |
| 成本     | 用户要求：免费部署，研究免费且快速的开放对话方案；持续额度与性能未验证                                 |
| 可访问性 | 用户要求：中国大陆用户可访问；须从大陆网络验证，云机器的访问结果不能代替                               |
| 内容     | 用户确认：题目硬编码，后续提供；本轮不编造正式题库                                                     |
| 数据     | 家庭隔离与进度持久化必需；用户确认家长授权外部 AI 处理；默认不保存原始音频或绘图，服务商保留政策需核查 |

## 暂不承诺

未选择托管、数据库、邮箱或 AI 服务；免费额度、实时速度和大陆访问均未证实。不将 AI 降级方案当作取消开放对话需求。代码编辑题目，暂无用户提出的在线出题后台。

## 第三轮确认

- 儿童使用昵称与 PIN 登录；家长生成单次使用的注册 KEY，并可重置儿童访问。
- 家长可查看完成进度、独立成功、提示使用、反复困难和复习建议，选择练习。
- 家长同意后可将必要的儿童输入交给外部 AI；默认不保存原始音频和绘图。
- 用户可提供 OpenAI API key，用于默认开启的付费 AI；必须节省 token。密钥仅在后端安全配置，不在聊天、前端或仓库保存。
- OpenAI 使用需要核查部署地区和目标用户是否符合当前支持地区与服务条款；海外服务器不自动意味着大陆终端用户符合使用条件。不能以代理或部署位置绕过服务限制。
- 免费托管仍是要求；付费 AI 预算及允许的替代方案待确认。

## 第四轮确认与框架验收范围

- 付费 AI 默认开启（用户最新指示，取代之前默认关闭的决定）；实际调用需安全配置密钥、核实服务资格并取得家长授权。预算之后设置，不再作为默认开启的前提；仍需节省 token 和提供用量控制。
- 交付空框架，不加入演示题目或虚构正式题目。没有题目时显示友好空状态，不伪造学习数据。
- 儿童可自由复习，家长可安排练习；第一版不强制按顺序解锁，题目顺序用于组织内容。
- 保存进度摘要与可恢复的当前草稿，支持家庭数据导出和删除，不永久保存原始录音或绘图。
- 草稿可能包含暂存绘图：其用途仅为恢复当前作答，不能变成永久作答档案；保存期限和清除条件须在实现前明确。
- 空框架验收：家长邮箱账号、儿童 KEY 注册与昵称/PIN 登录、家长重置、家庭权限隔离、题目导航空状态、家长面板空状态、设置与数据控制。
- 延后至真实题目接入后验证：教学交互、错误定位、语音与绘图理解、AI 教学质量、学习进步，以及三儿童同时进行真实学习的性能。
- 尚未建站、部署或验证服务。当前产物为产品需求，下一阶段为架构设计。
