# 路线图

本计划已获维护者确认，分为两个里程碑、56 个独立任务。进度以 GitHub issue 和里程碑状态为准，此文件只记录范围、依赖与验收安排。

基线：2026-11-04 的 main `3a73155`；PR #12、#13 均已合并，TypeScript 7 与自动合并修复已集成。账号、教学、语音/AI 和生产部署仍未实现。课堂公共部件的迁移步骤见 [课堂公共部件与绘景库](design/lesson-kit.md)，网站视觉改版的规格见 [网站视觉语言](design/visual-language.md)。

## 已确认范围

- 中文；正式题库只收用户提供的真实题目，逐题设计和实现。测试夹具仅用于隔离测试。
- React/TypeScript 7、Fastify、PostgreSQL/Drizzle；保持现有工具链和模块边界。
- 家长邮箱账号、儿童 KEY/昵称/PIN、家庭隔离、进度与练习、导出删除。
- 七天草稿，提交/放弃即清除，不保存原始音频；绘图仅作为有期限的草稿。
- 付费 AI 默认开启；预算未设置不改变该默认值。实际调用仍要求有效密钥、服务资格和家长授权；金额与操作限额需在相应任务细化，不默认为无限支出。
- 大陆访问必须实测；免费托管优先，失败后使用用户提供的服务器/域名。生产显式手动发布。

## 执行与验收规则

每个 issue 对应一个独立 PR。S 约 200 行以内、M 约 500 行以内，均为初估；实现前若预计超过 M，先按用户行为继续拆分，不以一个大 PR 完成整个模块。新功能的权限、失败与并发测试随本功能交付，[#47](https://github.com/juanchaopan/education/issues/47)/[#51](https://github.com/juanchaopan/education/issues/51) 是端到端验收，不是把安全检查拖到最后。

每项具体目标、需求、验收、组件、风险及测试见 [任务规格](roadmap-issues.md)；#125 以后的任务规格写在各自的 GitHub issue 里。风险按 `.github/risk-rules.txt` 预估：身份、数据库、协议、AI、部署和流程变更为高；其他应用代码通常为中；仅文档探针为低，若提交可执行原型须重新分类。中高风险 PR 由维护者确认，自动合并不代替 `human-reviewed`。

探针产出可复核证据和 ADR，不产出正式业务代码。[#14](https://github.com/juanchaopan/education/issues/14) 对应 ADR-0002/0006 和 Q-006；[#15](https://github.com/juanchaopan/education/issues/15)/[#16](https://github.com/juanchaopan/education/issues/16) 对应 ADR-0004 和 Q-001/004/005；[#27](https://github.com/juanchaopan/education/issues/27)/[#28](https://github.com/juanchaopan/education/issues/28) 对应 Q-003/006/007/011；[#29](https://github.com/juanchaopan/education/issues/29) 对应 ADR-0005 和 Q-009/010；[#48](https://github.com/juanchaopan/education/issues/48) 对应 Q-008；[#138](https://github.com/juanchaopan/education/issues/138) 对应 ADR-0016。未验证项不能通过文字决策变成已验证。
