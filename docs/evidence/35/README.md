# #35 家长学习摘要

家长验证邮箱并登录后，可以在家长空间选择一个孩子。摘要使用 #34 已提交的进度和提示事件，按题目和版本列出独立完成、提示后完成、提示记录、确认答错及无法判定的次数。已登记的版本显示题目标题，标题不可用时显示题目编号。只打开提示的题目也会列出。

同一轮的同一提示只计一次，重复提交沿用原回执。确认答错至少两次且尚无独立完成时，页面显示优先复习及对应次数。无法判定的作答单独展示。是否掌握仍需要逐题定义独立迁移证据。

服务端在家长会话事务中核对孩子归属。同一家庭内按孩子查询。其他家庭和未知孩子返回相同的 404。响应最多 20 个题目版本，按题目编号和版本排序，带有 `Cache-Control: no-store`。响应只含摘要字段，未增加数据库迁移。

## 验证

- PostgreSQL 17 专项测试通过 #34 实际作答接口生成隔离记录，验证去重、版本、复习建议、无法判定、提示单独记录、兄弟姐妹、跨家庭、会话撤销与分页。
- Playwright 在桌面和手机视口验证真实家长登录、选择孩子、复习依据、切换到无记录的孩子、退出后隐藏摘要和无横向溢出。
- Storybook 包含有证据及无记录两种状态。浏览器及 Storybook 数据均为合成夹具。
