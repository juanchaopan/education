# #126 数轴追及：两车的中点什么时候相距 4 格

状态：实现完成，等待 CI、录音试听和维护者审核。分镜（18 幕）由维护者 2026-11-12 确认；本记录写下选定的流程、讲法、部件和背景，实现和分镜不同的地方，以及自查卡的状态。

## 题目

六年级学而思讲义的数轴追及题，放在新书 六年级 / 数学 / 学而思（`g6-math-xueersi`，先用默认的科目封面），题库标题「两车的中点什么时候相距 4 格」，题目标识 `rail-chase` 第 1 版：黄车长 2 格，中点 M 在 −1；蓝车长 6 格，中点 N 在 9；两车同时向右开，黄车每秒 2 格，蓝车每秒 1 格。经过几秒 M、N 相距 4 格？答案是 6 秒和 14 秒，按集合判。

## 提问的记录

画面快照说：两车开了几秒、两车每秒各走几格；画出空隙格以后，M、N 之间隔几格；起点十格亮出以后，金格和还没变金的格子各几格；点亮了几张「谁在前」小图；谁在前或两点对齐；推导板最新一行是哪一步；停在时刻上时标着「相距四格」。推导板每一步都有一个状态的用词，作答以前的快照不写 6 或 14。关键操作是推车、点车、点起点的一段、点还没变金的一段、点空隙、点题目里的「4 格」和点亮两张小图；常见误操作是车停下以后还推、在车不动的一幕推车、点了这一步还不用点的地方。

## 和确认的分镜不同的地方

- **版面上下压紧了一些。** 背景的空地是 y 265–595，分镜的式子板伸到了 604。题目条、两条轨道、空隙格、起点十格和推导板的位置往上收，两张「谁在前」小图放到起点十格下面的左边，不再放在轨道上方的右边（那里会压住跑到右边的黄车）。
- **变化题的猜和理由暂时不记录。** 分镜第 17 帧的作答胶囊「记下了：3 秒、7 秒」要用变化题的作答部件（#218）和记录接口（#217）。现在旁白请孩子先在心里猜，再推车核对、想一想为什么，最后揭晓；接入 #217、#218 以后改成分镜的做法。
- **提示不点亮推导板上的那一行。** 题目的画面看不到作答时收到的提示，提示的话本身说了看哪一行（「先看蓝车在前那一行」）。要点亮那一行，需要把作答进度交给题目的画面，作为公共部件的改动另外提出。
- **点车只走一秒，往回拉只到这一幕开始的地方。** 和分镜一致；方向键左右也各走一秒。

## 旁白

67 句，用 `npm run lesson:narrate -- rail-chase` 录（edge-tts，`zh-CN-XiaoxiaoNeural`，语速 −14%、音高 +5Hz，不收费），录音在 `apps/web/src/features/learning/lessons/rail-chase/assets/`。每一幕的进场台词先说现在在哪一步、在找什么。

旁白按手册「讲解和这本书的年级相称」改过一轮（维护者 2026-11-12）：十减 t 从一开始就叫「蓝车领先几格」，算出负数读成「领先负一格，就是黄车反过来领先一格」，不再说画面上没有的「位置」；起点的十格一起亮出来，说「数一数，一共十格」，不再从一数到十；「有方向的差」换成「蓝车领先负四格，也就是黄车领先四格」；进场台词不再重复上一幕最后一句；两条提示用画面上的道理带孩子算出第几秒（「先追回十格对齐，再多追四格」）。改过的 23 句重新录了音，维护者已试听。
