# #164 家长总览：样稿

[#164](https://github.com/juanchaopan/education/issues/164) 的样稿，等维护者确认。设计见 [家长总览：最近 7 天、学习时长和家庭时区](../../design/family-overview.md)。

## 怎么做的

样稿是一次性的 HTML，直接用网站的设计令牌（`apps/web/src/styles/tokens.css`），家长空间的侧栏、标签栏、卡片和设置列表照现在的页面近似画出。用 Playwright 的 Chromium 截图：桌面 1280 宽，手机 390 宽，减弱动画，整页截图；截图转成 256 色 PNG 以减小文件。样稿代码不进入仓库。

和正式页面的差别：

- 标题用 Windows 的系统楷体代替霞鹜文楷，字形略有不同；图标是照着 `shared/ui/icons.tsx` 的样子简画的。
- 「已安排」的封面是纯色块，正式页面照 #179 显示封面或默认封面。
- 手机截图是整页截的，底部标签栏画在页面最下面；正式页面上它浮在屏幕底边。
- 总览设置列表里新加的「家庭时区」一行用虚线框标出来，只为在样稿里好找，正式页面没有虚线框。
- 数字都是样稿用的例子。今天是 2026 年 11 月 12 日周四，最近 7 天是 11 月 5 日到 11 月 11 日。
