# #24 儿童用 KEY 自助注册

日期：2026-11-05。需求：REQ-002；依赖 #23 已关闭。实现基于 main `17d03af94c4307eedc3f97be0350a399a22e60dc`，工作分支 `feature/24-child-registration`。

## 当前行为

- `/join` 提供中文 KEY、昵称、六位数字 PIN 表单；主导航和家长 KEY 面板说明注册入口。成功后清空 KEY/PIN，只显示昵称、家庭码及下一版本登录说明，不签发会话。儿童登录和持久会话属于 #25；家长重置儿童访问属于 #26。
- KEY 去除分组短横线并转大写，按 16 位 Crockford Base32 校验；服务端只接收其 SHA-256 哈希进入仓储。昵称先 NFKC、去首尾空白，限定 1–12 个 Unicode 字母/数字；另存小写规范名，家庭内唯一，跨家庭可同名。
- 六位 ASCII 数字 PIN 允许前导 0，拒绝全相同和明显连续顺/逆序。独立 `PIN_PEPPER` 对 `[版本1, familyId, childId, PIN]` 的 JSON 编码做 HMAC-SHA256，再执行 Argon2id m=32768 KiB、t=3、p=1；数据库保存哈希和 pepper 版本。明文 PIN 不进入数据库、日志、localStorage 或 sessionStorage。
- 兑换事务锁定家庭，再条件消费仍有效、未撤销、未消费的 KEY，同时创建儿童和回执。与 #23 替换/撤销、#22 家长恢复使用同一个家庭锁；有效期按拿到锁后的数据库时钟检查。昵称冲突、哈希失败、约束错误均回滚 KEY 和儿童写入。
- 家庭首次成功兑换时生成 12 位随机 Crockford Base32 家庭码，数据库唯一约束；后续儿童共用该码。家庭码只是后续登录定位信息，不授予访问权，也不提供登录前儿童列表。
- 浏览器为一次输入生成请求 UUID，未改输入的显式重试使用同一 UUID，不自动重试写入。数据库仅保留 HMAC 请求标识、绑定原 KEY/显示昵称/规范名/PIN 的 HMAC 指纹、儿童与 KEY 外键；24 小时内同请求返回同一回执，内容不同则拒绝。新请求不能再次消费已用 KEY。回执不签发新会话，页面刷新后也不保留原输入；响应丢失且已刷新时，使用原凭据恢复登录的能力由 #25 提供。
- `child_registrations` 在后续兑换时清理超过 25 小时的记录；没有流量时不保证定时物理删除。儿童账号和家庭关联不因此过期。
- 兑换与家长认证共用同一哈希并发准入：进程最多 2、数据库全局最多 4。兑换计数有独立命名空间：每 KEY 5 次/15 分钟、来源 10 次/15 分钟与 50 次/日、兑换全局 100 次/15 分钟与 500 次/日；成功和回执重试也计数。桶键 HMAC 化，最多 25 小时窗口清理，不以更换来源绕过 KEY 桶。
- POST `/api/v1/children/register` 要求精确同源、JSON、自定义头和严格请求/响应 schema，拒绝额外 familyId/childId 等字段或查询参数；响应 no-store。错误为中文，服务端日志不记录请求体或原始异常消息。

## 数据库和配置

迁移 `0006_round_scream.sql` 添加可空且唯一的家庭码、规范昵称、可空 pepper 版本和幂等回执表；回执表随 staging 迁移启用 RLS，并撤销 anon/authenticated 权限。已有昵称以 PostgreSQL NFKC/小写回填再建家庭内唯一索引；若历史记录规范化后冲突，迁移应失败并由维护者处理，不能静默合并儿童。此前没有儿童注册入口，旧夹具/手工数据的空 pepper 版本不能当作有效的新 PIN 凭据；后续登录须拒绝未保护的旧凭据。

服务端 `PIN_PEPPER` 为 64 位十六进制、独立 32 字节随机密钥；缺失时儿童接口返回 503，家长账号能力仍可用；配置了错误格式则启动失败。GitHub Actions 从 **Secret `STAGING_PIN_PEPPER`** 读取并作为 Vercel runtime env 传递；发布流程缺失或格式错误时不创建候选。维护者已回复完成配置，未读取或记录其值。密钥跨部署保持稳定，不随发布重新生成；当前版本不提供 pepper 自动轮换/丢失恢复，丢失后需通过后续家长重置流程处理。

## 撤回

撤回应用 PR 或将 staging alias 恢复至兼容同数据库的上一版本；保留新增表、列、家庭码和儿童记录，不执行破坏性 down migration。旧应用忽略新增字段。撤回时仍须在密码管理器中保留原 PIN_PEPPER；移除 GitHub Secret 会阻止后续 staging 发布，不能据此声称已停用线上入口。丢失原密钥将使已有 PIN 无法验证。回滚应用不等于回滚已消费的 KEY 或删除儿童。

## 家长查看家庭码的补充

维护者要求家庭码在家长页长期可查看、可复制，不让孩子或家长背新代码。家长现有 KEY 状态接口在验证当前家长所属家庭后，返回已分配的固定家庭码；还没有儿童成功注册时省略该字段，页面说明首次注册后显示。刷新、重新生成或撤销邀请 KEY 不改变家庭码。共享协议复用同一家庭码格式，展示组件仍不取数据；复制只在明确点击时写入剪贴板，失败可手动选取。家长页的展示见 [手机](family-code-mobile.png) / [桌面](family-code-desktop.png)；均为合成数据。此前未展示家庭码的家长 KEY 面板见 [#23 截图](../23/after-mobile.png)。
