# 中文朗读与重复播放指令

[#42](https://github.com/juanchaopan/education/issues/42) 让儿童随时重听当前这一步的讲解，可以暂停、继续或从头听，文字始终在屏幕上。对应 REQ-003、REQ-004，按 [ADR-0012](../../adr/0012-browser-voice-touch-spike.md) 的朗读方案实现。

## 声音

旁白用 [edge-tts](https://github.com/rany2/edge-tts) 的 `zh-CN-XiaoxiaoNeural`，语速 −14%、音高 +5Hz，逐句合成、按教学动作断句，存成 24 kHz、48 kbit/s 的单声道 MP3。这是 #48 原型的 `story-voice.py`、`pencil-voice.py`、`rail-voice.py` 用的声音（生成脚本在归档标签 `archive/spike-48-interactive-lessons`），菜园题的 14 段旁白就是原型的录音。维护者在 #136 试听了本地 Piper `zh_CN-huayan-medium`、Kokoro-82M 的四个中文女声和 MeloTTS 的中文声音，认为都不如 Xiaoxiao。

声音写在 `scripts/lesson-voice.json`：`engine` 是合成引擎，引擎名下是它的设置。`npm run lesson:narrate -- <题目文件夹>` 按台词录下缺少或改过的句子，并在这道题的 `assets/narration.json` 记下每段录音的文字和声音，见 [README](../../../README.md)。

- 每道题的旁白在出题时由维护者预先生成为静态音频文件，随页面一起发布。孩子使用时不调用任何在线服务，不发送孩子的任何信息，也不产生费用，所以不涉及 #37/#39 的授权与用量控制。
- 每段音频仍要在所在的题目里实际试听，确认断句、停顿和音画同步，见[逐题设计互动教学与验收手册](../../design/interactive-lesson-authoring.md)。
- **条款需要维护者确认**：edge-tts（LGPL-3.0）调用的是微软 Edge 未公开的在线朗读接口，不是开源的声音模型，也没有面向开发者的服务条款。用它生成要发布给儿童的音频是否符合微软的条款不明确，正式给儿童发布前需要维护者确认，否则换用许可明确的声音。播放功能与声音无关，换声音只需改 `scripts/lesson-voice.json`，再用 `--new-voice` 重新录音。

## 播放规则

| 情况                 | 行为                                                                                                                         |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 播放中点「从头听」   | 同一个音频元素回到开头重新播放，不会同时响两段；场景仍等这段真正播完才进入下一步                                             |
| 播完后点「再听一遍」 | 再播一次这一段。场景的下一段开始时，正在重听的这段立即停止，下一段不会因为「正在播放」被拒绝                                 |
| 连续快速点           | 每次都是从头播同一段，任何时候只有一段在响                                                                                   |
| 暂停、继续           | 暂停后场景停在原处，继续时从暂停的位置接着播；暂停期间场景在同一步发来的下一段被拒绝（`busy`），不会排队                     |
| 暂停的是重听         | 孩子操作后场景的下一段照常接替被暂停的重听，和没暂停时一样                                                                   |
| 换到下一步           | 上一步的声音立即停止并被忘掉，之后点重听不会播出上一步的话。场景在换步的同一时刻为新一步开始的那段不受影响                   |
| 页面切到后台         | 暂停，回来后由孩子点「继续」，不会突然自己响起来                                                                             |
| 离开课程             | 停止播放                                                                                                                     |
| 这一步没有音频       | 只显示文字，不显示播放按钮                                                                                                   |
| 声音放不出来         | 浏览器拒绝自动播放或音频加载失败时，文字照常显示，并说明「声音没有放出来，看上面的字也可以」；孩子点「再听一遍」可以再试一次 |

## 组成

- **`interaction/narration.ts`**：`createNarration` 在 #31 的按序播放、暂停续播和停止之外，提供 `replay()` 和播放状态（`silent`、`ready`、`playing`、`paused`、`failed`）。每段旁白属于一个步骤：场景用 `play(stepId, source, onCue)` 按教学顺序播放，用 `onCue` 同步字幕和高亮；`keep(stepId)` 停止并忘掉不属于这一步的旁白。
- **`interaction/useNarration.ts`**：`useNarration(stepId)` 在步骤变化时调用 `keep`，并负责切到后台和离开课程时的处理。
- **`components/NarrationCaption.tsx`**：显示当前这段话的文字（`aria-live="polite"`，读屏软件会读出新的一段），按状态提供「再听一遍」「暂停」「继续」「从头听」。
- 题目页面用 `onCue` 把这一段的文字交给 `NarrationCaption`；孩子点重听时，页面可以按 #31 的 `createLessonHelp` 记录一次 `replay`。

## 自动化检查

- **旁白**：播放中和暂停时重听都在同一元素上从头播、不新建音频，场景仍等到真正结束；播完后重听用新元素，并让位给场景的下一段；放不出声时报告并可重试；停止后不能重听；没有音频时直接显示文字；新一步的旁白取代上一步的，`keep` 只停其他步骤的旁白；原有的按序播放、暂停续播、暂停前迟到的播放失败和停止后不再揭示字幕仍然成立。
- **步骤绑定**：换步骤时上一段被取消且不能重听，换步同时开始的新一步旁白继续播放，切到后台时暂停，离开课程时停止且之后的后台事件不再触发。
- **面板**：每种状态显示的文字和按钮，以及按钮调用的操作。
