# 家长管理外部 AI 处理授权

[#37](https://github.com/juanchaopan/education/issues/37) 实现 REQ-003、REQ-008、REQ-009 的授权管理。已验证邮箱的家长可以在家长空间分别授权或撤回 OpenAI 解题提示、普通话语音转写。页面说明用途、发送内容、应用与供应商各自的保留规则，以及撤回对已发送内容的影响。修改前复用五分钟密码重认证。

## 决定如何生效

- 每个家庭和服务用途最多保存一行，包含政策版本、授权状态、决定修订号和更新时间。按家庭删除时级联清理。授权表不存儿童输入、密码或会话。
- 服务端从会话取得家庭身份。申请授权需匹配当前政策和页面读到的决定修订号。过期页面或重放的旧授权请求返回冲突，撤回后的授权需再次明确确认。
- 网关在每次发送前使用 `createAiConsent(pool).dispatch(credentials, scope, start)`。它在同一事务中验证儿童会话及 CSRF、读取该家庭当前用途的授权，再启动供应商请求。家长更新和儿童发送共用家庭行锁。撤回一经提交，后续请求无法进入适配器。已发出的数据按供应商的政策处理。
- `start` 在锁内发起一次请求，使用传入的五秒取消信号并及时返回响应句柄。收到句柄后在事务外读取流。适配器应在发起前做好数据准备和用量预留，避免在锁内开启另一家庭事务，禁止后台另起发送或自动重试。
- 更换服务、用途、输入范围或保留规则时更新对应政策版本。旧版本的授权不会通过新版检查。启用实际外发后，切换政策版本时先停止旧部署的外发流量，再启用新版。

## 供应商接入边界

本轮用测试替身验证发送边界。实际调用由 #38 和 #41 接入，届时须另外验证部署、账号和端点的处理资格与保留设置。OpenAI 对低于 13 岁或当地数字同意年龄儿童个人数据的要求，及图像安全审查例外，见官方说明。 [未成年人指南](https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance) [端点数据控制与保留](https://developers.openai.com/api/docs/guides/your-data)
