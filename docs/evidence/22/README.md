## 实现

- 登录页恢复入口、中文申请/新密码页面，展示组件有 Storybook 正常、等待、失败和长文状态。合成截图：[原登录页](before.png)、[新登录入口](after-login.png)、[恢复申请](recovery.png)、[新密码](reset.png)、[手机](reset-mobile.png)。截图来自本机 Chromium，不是 126 或 Vercel 实测；固定官方 Playwright 镜像的像素基准仍未建立，不称为像素回归通过。
- 共用 Gmail TLS 适配器与资源无外链的 multipart 邮件布局；验证与恢复合并计算站点发信预算，恢复尝试独立于登录预算，共用有界资源准入。
- 持久化受保护投递意图，30 分钟单次令牌、显式同令牌有界重试与替换旧链接；不存在/限流/失败通用回执，健康 SMTP 路径采用 20 秒响应下限。
- 实际 PostgreSQL 事务修改密码、增加凭据版本和家庭 epoch、撤销旧会话/未消费 KEY 与邮件令牌；无自动登录、无未验证提权、不修改账号/家庭关联/草稿。
- 0004 为增加表的迁移，新表纳入 Supabase 风格 RLS/撤权与现有小时清理任务。配置与恢复说明见 [账号邮件](../../deployment/mail.md)。
