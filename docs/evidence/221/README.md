# #221 孩子只学安排的书，访客看不到题目：样稿

[#221](https://github.com/juanchaopan/education/issues/221) 的样稿，待维护者确认。设计见 [孩子只学安排的书，访客看不到题目](../../design/book-access.md)。

## 怎么做的

样稿是一次性的 HTML，直接用网站的设计令牌（`apps/web/src/styles/tokens.css`）和绘景库里的图（傍晚的画室、玩具教室、雨夜的图书角、清晨的菜园和小兔），按设计里「立体感」一节画：页面顶上是有景深的画，能点的东西凸起，输入框凹下，书是立体的，画上的字和按钮是烟色玻璃。图标照 `shared/ui/icons.tsx` 画。用 Playwright 的 Chromium 截图：桌面 1280 宽，手机竖放 390×844、横放 844×390，减弱动画；截图转成 256 色 PNG 以减小文件。样稿代码不进入仓库。

和正式页面的差别：

- 标题用 Windows 的系统楷体代替霞鹜文楷，字形略有不同。
- 孩子「小米」、书名、题目、进度和学习时间是样稿用的例子；书的封面都画成默认封面。
- 预览作答那张图的题目、选项和点选的样子是示意，正式页面用每道题自己的作答部件。
