# #179 家长书架：样稿

[#179](https://github.com/juanchaopan/education/issues/179) 的样稿，维护者 2026-11-12 确认。设计见 [家长书架与按书安排练习](../../design/bookshelf.md)。

## 怎么做的

样稿是一次性的 HTML，直接用网站的设计令牌（`apps/web/src/styles/tokens.css`），家长空间的侧栏、标签栏和卡片照现在的页面近似画出，图标照 `shared/ui/icons.tsx` 画。用 Playwright 的 Chromium 截图：桌面 1280 宽，手机 390×844，减弱动画；截图转成 256 色 PNG 以减小文件。样稿代码不进入仓库。

和正式页面的差别：

- **封面是占位**：有图的封面是从绘景库里裁出来的竖版画面，只为看出书卡上有图时的样子；正式的封面按 [风格说明](../../design/lesson-media.md#书的封面) 由维护者在 Codex 里生成，绘景不会拿来当封面。没有图的书卡画的就是设计里的默认封面。
- 书名、题数、进度和孩子都是样稿用的例子，题目清单里现在只有「一年级 / 数学 / 学而思」一本书。
- 标题用 Windows 的系统楷体代替霞鹜文楷，字形略有不同。
- 孩子「我的练习」为了截图不太长，每本书只画了前几道题，下面写「还有 6 道…」；正式页面列出书里的全部题。

样稿里的家庭有小米和乐乐两个孩子。「儿歌和童谣」是一本暂时不可用、安排给了小米的书；「拼音乐园」小米以前安排过又取消了，留有 3 道的进度。

## 维护者的选择

2026-11-12 看过第一版样稿后：

- 选孩子放在最上面单独一行，不写「给谁」「年级」「科目」这些标签文字，读屏标签照常保留。
- 底部的后备按钮写「加载更多」。
- 书卡上不写「已做 n / m」那行字；进度标在封面的角上，看一个孩子时在右上角，学完换成带勾的样子；看多个孩子时在右下角，例如「小米 5/10」。
- 看一个孩子时，年级和科目后面加一组全部、已安排、未安排；总览「已安排」链到这个孩子的「已安排」。
- 书有状态：可用、暂时不可用（例如版权问题），写在书的定义里，由维护者改。
- 新科目的图标和底色由 agent 在导入 PDF 时按现有风格画，出截图给维护者确认。
- 同意按书分两个 PR，同意两个 PR 之间旧页面上的单题安排会被丢弃；孩子练习的排列、书架上学完的书不挪位置、手机上点「已安排」直接取消、书里还没题的书不出现在书架上都按设计做。

2026-11-12 看过第二版样稿后：

- 最上面一行是「书库」「我的家庭」和每个孩子，默认书库。书库只列还没安排给任何孩子的可用书，安排后这本书进入我的家庭；我的家庭列出安排给孩子的书，右下角标每个孩子的进度，暂时不可用的也在这里置灰显示。
- 点「安排」一律弹出孩子列表，家里只有一个孩子时也弹出。
- 暂时不可用的书，孩子看到的和家长一样：在「我的练习」里置灰，写「暂时不可用」，题打不开。
- 孩子只能学家长安排过的书，没登录的访客什么都看不到；这条访问规则由 [#221](https://github.com/juanchaopan/education/issues/221) 做。孩子视角下，没安排的书只在以前安排过、取消后留有进度时才标进度。
- 还没有孩子时也能看书架，顶部放邀请卡；总览「已安排」按书单顺序、几个孩子轮流取。

2026-11-12 维护者确认了按上面两轮意见改过的这一版样稿和设计。
