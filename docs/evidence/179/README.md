# #179 家长书架：样稿

[#179](https://github.com/juanchaopan/education/issues/179) 的样稿，等维护者确认。设计见 [家长书架与按书安排练习](../../design/bookshelf.md)。

## 怎么做的

样稿是一次性的 HTML，直接用网站的设计令牌（`apps/web/src/styles/tokens.css`），家长空间的侧栏、标签栏和卡片照现在的页面近似画出，图标照 `shared/ui/icons.tsx` 画。用 Playwright 的 Chromium 截图：桌面 1280 宽，手机 390×844，减弱动画；截图转成 256 色 PNG 以减小文件。样稿代码不进入仓库。

和正式页面的差别：

- **封面是占位**：有图的封面是从绘景库里裁出来的竖版画面，只为看出书卡上有图时的样子；正式的封面按 [风格说明](../../design/lesson-media.md#书的封面) 由维护者在 Codex 里生成，绘景不会拿来当封面。没有图的书卡画的就是设计里的默认封面。
- 书名、题数、进度和孩子都是样稿用的例子，题目清单里现在只有「一年级 / 数学 / 学而思」一本书。
- 标题用 Windows 的系统楷体代替霞鹜文楷，字形略有不同。
- 孩子「我的练习」为了截图不太长，每本书只画了前几道题，下面写「还有 6 道…」；正式页面列出书里的全部题。

## 维护者的选择

2026-11-12 看过第一版样稿后的修改：

- 选孩子放在最上面单独一行，选项依次是「全部」和家里的每个孩子；不写「给谁」「年级」「科目」这些标签文字，读屏标签照常保留。
- 底部的后备按钮写「加载更多」。
- 书卡上不写「已做 n / m」那行字。
- 选「全部」时看系统里现在可用的全部书；安排给了哪个孩子，在封面右下角标孩子和进度，例如「小米 5/10」，安排给几个孩子标几个。在「全部」里怎么安排和取消，由开发者提方案画进样稿。
- 选一个孩子时，年级和科目后面加一组全部、已安排、未安排；进度在封面右上角，学完时换成带勾的样子；总览「已安排」能链到这个孩子的「已安排」筛选。
- 书有状态：可用、暂时不可用（例如版权问题），写在书的定义里，由维护者改，代替「从书单里撤下」。暂时不可用的书，安排过的显示成置灰的书、写「暂时不可用」、可以取消；没安排过的看不到。孩子那边还没定，两种做法都画了。
- 新科目的图标和底色由 agent 在导入 PDF 时按现有风格画，出截图给维护者确认。
- 同意按书分两个 PR，同意两个 PR 之间旧页面上的单题安排会被丢弃；第一版列的孩子练习的排列、书架默认全部年级和科目、学完的书不挪位置、手机上点「已安排」直接取消、书里还没题的书不出现在书架上，维护者没有反对。
