# AI 解题提示用量与费用上限

[#39](https://github.com/juanchaopan/education/issues/39) 为文字解题提示网关增加跨实例预算和限流，对应 REQ-008。

- `AI_MONTHLY_BUDGET_USD` 接受非负美元小数，最多九位整数和九位小数。未设置时，家长空间显示「AI 解题提示预算未设置」。设置为 `0` 会阻止这类付费请求。所有共用数据库的实例应在启用发送前完成迁移并使用同一配置。变更预算时，先停用付费发送，待所有实例使用新配置后再启用。
- 预算按数据库记录的准入时间归入 UTC 自然月，覆盖本部署经此网关发出的文字解题提示。每个儿童每分钟最多准入 6 次，同一家庭最多 18 次。这些是试点限流值。预算金额和生产额度留待维护者确认。付费开关的默认值保持开启，发送仍需满足密钥、资格和当前家长授权。
- 固定预留 US$0.002112，覆盖文字请求的 16,384 输入 token 预算、128 输出 token 上限及标准服务的缓存写入费率。请求还受字节上限和题目步骤、提问长度约束。结算使用供应商报告的 token 数，按标准服务的 30 分钟缓存写入费率为输入作保守估值。估算使用当前费率，部署前需确认项目服务等级及费率。 [GPT-6 Luna 定价](https://developers.openai.com/api/docs/models/gpt-6-luna) [OpenAI 缓存计价](https://developers.openai.com/api/docs/guides/prompt-caching)
- 请求启动前提交预留，并在家庭锁内再次检查会话和授权。确定未发送或供应商拒绝认证时释放。取消、连接故障、缺少最终用量或进程退出均保留预留金额。返回超出计价边界的用量或服务等级时，阻止本月后续调用。限流、额度不足或无法给出提示时，课堂仍可使用题目的引导模式。
- 账本保存模型、token、金额估计和状态，家庭与儿童关联仅用于限流。删除家庭或儿童时清除相应关联，避免已发生的费用从当月预算中消失。待核对额度仍计入准入月份。

自动化用合成响应验证两个数据库连接池争用同一笔额度、拒绝释放、取消保留、幂等结算和未设置预算时的限流。
