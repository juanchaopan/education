# #143 题目页样稿：画面全屏，控件嵌进画面

[#143](https://github.com/juanchaopan/education/issues/143) 的样稿和维护者的选择。

## 为什么重画

维护者在 staging 看菜园题时，提问区和作答区放在画面下面单独一大块，把动画挤小了；[#138](../138/README.md) 的样稿里也还是画面下面一条栏。维护者要求整个动画占满屏幕，控件用和绘景风格一致的手绘图标嵌在画面里，字尽量少。

样稿用一次性的 HTML、CSS 和 SVG 画，图片只用了菜园底图和小兔；图标、结论板和控件都是代码画的。

## 两个方向

- **A 菜园里的小物件**：控件做成画面里的东西，木头路牌返回、挂在树枝上的木片、萤火虫罐子提示、带兔耳朵的黏土麦克风，结论板是画架上的小黑板。童话感最强，但占地方，每张新底图都要重新摆放。
- **B 露珠**：控件是画面边上的玻璃露珠，结论板是天空上一排玻璃胶囊，小兔的话像电影字幕。遮住画面最少，任何底图都能直接用。

## 维护者的选择

2026-11-10：选 B，提示按钮用 A 的萤火虫，改成装萤火虫的玻璃露珠。提问按维护者描述的流程画：

- 话筒在右下角。按住时，孩子说的话实时出现在话筒旁边的文字框里。
- 松开后，文字框旁边出现提交图标，点一下就发给小兔。
- 不点提交时，孩子可以点文字本身，把光标放进去修改；也可以不改。
- 想重说就再按住话筒；文字框角上有一个 × 可以不问了；讲述暂停时，小兔头像上的播放角标接着讲。

控件、字幕、结论板和提示都做成课堂公共部件，供每一道题的题目页使用。

实现前维护者又定下：按住时文字框里只显示跟着声音动的音量条，松开后才出现转写的文字，不做实时转写；字幕和声音开关记在设备上。其余取舍见 [课堂公共部件与绘景库](../../design/lesson-kit.md#题目页的画面和控件)。

- 平板横放 1180×820：![](built/tablet-landscape.jpg)
- 平板竖放 820×1180：![](built/tablet-portrait.jpg)

和样稿的不同：

- 结论板（#181）还没做，顶部居中空着。
- 横着的屏幕上，作答胶囊在下方一行、话筒旁边，不在字幕上方居中，免得 16:9 的屏幕上压到天平底座。
- 竖屏的道具按题目的道具范围放到屏幕宽度，范围包括旁边的篮子，所以天平比样稿略小。
- 已登录的孩子在右上角（竖屏在字幕下面）看到「草稿已保存」的提示条，样稿没有画。

## 实现时要注意

- 手机竖屏让底图铺满屏幕，道具按屏幕宽度摆在桌面上；课堂舞台现在只截取画面中间一段、四周补模糊底图，这条规则要跟着改。
- 提示只在作答那一幕出现，提问的样稿里没有提示按钮。
- 手机键盘弹出时文字框移到键盘上方，要按 `visualViewport` 等方式判断键盘占的高度，iOS 和 Android 的表现不同，要在真机上核对。
- 标题字体用的是系统楷体，正式字体按视觉语言的规定。
- 截图是减弱动画下的静止画面；光标闪动、话筒光圈和按下效果按视觉语言的动效规定做。
