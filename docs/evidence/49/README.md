# #49 第一道真实题目：菜园天平

状态：实现完成，等待 CI 和维护者审核。另外两道样例题由 [#125 彩铅配对](https://github.com/juanchaopan/education/issues/125) 和 [#126 数轴追及](https://github.com/juanchaopan/education/issues/126) 接入；进题后不用按键就能随时和老师对话，是维护者提出的新需求，先用 `/change` 评估。

## 题目

一年级试卷第 7 题，放在 一年级 / 数学 / 学而思，题库标题「一棵青菜有多重」，题目标识 `garden-balance` 第 1 版：两棵青菜和六个苹果一样重，一个苹果和三根黄瓜一样重，一棵青菜和几根黄瓜一样重？答案 9 根。

## 从 #48 原型原样保留的

原型是归档标签 `archive/spike-48-interactive-lessons` 里的 `garden-story.html`。正式页面用 React 重写，孩子看到、听到、操作到的和原型一致：

- 分镜顺序：开场 → 把一棵青菜拖进篮子 → 苹果一边沉下去，拿走苹果直到秤回到中间 → 碰一碰苹果，看到三根黄瓜 → 三个苹果一个个换成黄瓜，秤一直是平的 → 变式：每个苹果只换两根 → 什么没变、什么变了。
- 素材：菜园背景和兔子园丁两张图是原型里 Codex 内置图像生成的成品（WebP，与归档文件逐字节相同）；青菜、苹果、黄瓜、篮子和天平的 SVG 路径、渐变和颜色不变；原型实际用到的 14 段 Piper 旁白从原型里取出存成 MP3，字幕文字不变。原型里早期版本留下、最终流程没用到的 5 段台词没有搬。
- 行为：秤的倾斜规则（每多一个苹果低 11，最多 33；单个苹果对空盘 −22）、提示音的音高、闪光指引、镜头推近、兔子说话时的动作、重听按钮、新的操作打断正在说的话、拖动或先点再点篮子两种操作、窄屏的取景。原型里一段声音 11 秒内不结束就接着往下演；正式页面只对一直没开始播放的声音这样做，正在播放或因提问暂停的声音等它真正结束。

## 补充的部分

- **最终作答（维护者确认）。** 三个苹果都换完后，孩子说出「一棵青菜和几根黄瓜一样重」。页面念出听到的内容和其中的数，孩子确认后才提交；没听出唯一的数时请孩子再说一次，不提交。整句「一棵青菜和九根黄瓜一样重」按“根”前面的数听成 9，「一样」「一共」里的“一”不算数。服务器判定：9 为正确，其他整数为答错。说 3 提示“这是一个苹果换的根数”，说 6 提示“这是一开始苹果的个数”，其他数提示一组一组地数。两条作者提示按顺序给出，用过提示再答对记为提示后完成。开口作答时旁白暂停，麦克风只听孩子。
- **说不了话时（维护者确认）。** 麦克风被拒绝、设备不能录音、家长未同意语音转写或语音转写不可用时，才显示 1–12 的数字按钮。只是这一次没录到、没听清或太慢时，请孩子再说一次。答错后数字按钮保留。
- **中间提问（维护者确认）。** 作答那一幕之外的每一幕都可以按一下问小兔，听到的话直接交给这一幕的老师，不需要确认，也不记作答。提问时旁白暂停，答完可以接着听；场景往下走了，回答仍然显示。老师答不了时显示这一幕自己的指引。回答以文字显示，原型里没有老师的实时语音。作答那一幕只有一个麦克风给答案用，需要帮助时用作者写的提示。
- **保存进度。** 登录的孩子每到一幕（作答之前）就保存草稿；再打开时按钮变成“接着上次的地方”，从那一幕开头继续。找上次的地方时开始按钮先不能点，免得从头开始盖掉进度。答对后放弃草稿，变式部分不再保存。
- **没登录时。** 可以看短片、操作道具，页面下方提示在孩子空间登录后才能保存、提问和交答案。
- **声音放不出来时。** 字幕按字数停留一段时间再往下走，孩子能读完。

## 本地浏览器（2026-11-08）

构建后的 API 连本地 PostgreSQL 17，用 Chromium 打开 `/problems/garden-balance/1`：

- 没登录时，从开场拖青菜、拖三个苹果、碰苹果、换三次黄瓜走到作答，每一幕的画面、字幕和原型一致；控制台只有孩子会话检查的 401。
