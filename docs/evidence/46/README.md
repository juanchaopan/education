# #46 固定视觉基准与儿童可访问性检查

[#46](https://github.com/juanchaopan/education/issues/46) 在固定的浏览器和中文字体环境里建立经维护者评审的截图基准，并自动检查儿童界面的可访问性。对应 REQ-003、REQ-004、REQ-007；目标见 [架构总览的视觉验证](../../architecture/overview.md#视觉验证已确认) 和 [ADR-0003](../../adr/0003-web-details.md)，做法见 [视觉基准与可访问性检查](../../design/visual-baselines.md)。

## 固定环境

- 镜像 `mcr.microsoft.com/playwright:v1.64.1-noble`，版本号取自 `package-lock.json` 的 `@playwright/test`。镜像内中文字体只有文泉驿正黑（`fc-match sans-serif:lang=zh-cn` 为 `wqy-zenhei.ttc`，包 `fonts-wqy-zenhei 0.9.45-8`），页面字体栈里的 PingFang SC、Microsoft YaHei、Noto Sans CJK SC 在镜像里都回落到它。
- 本地和 CI 都运行 `npm run test:visual`，镜像里先 `npm ci`、构建应用和 Storybook，再运行测试。CI 的 `visual` job 是 `ci` 汇总检查的一部分，失败时上传 `visual-diff`。
- 基准不会被普通运行写入（`updateSnapshots: 'none'`）；`*-snapshots/**` 在 `.github/risk-rules.txt` 里是高风险路径，基准变化须维护者看图确认。

## 覆盖范围

桌面（1280×720）、平板（iPad 810×1080）、手机（iPhone 13 390×664）三个视口，按 1 倍像素截图，共 420 张基准。

| 内容            | 数量                  | 状态                                                                                                                                            |
| --------------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| Storybook story | 126 个 × 3 视口 = 378 | 正常、空、加载中、失败、长文字；朗读的“再听一遍”和暂停、声音没出来；AI 反馈、没听清、用量受限、超时；画板的区域反馈和不确定                     |
| 页面状态        | 14 个 × 3 视口 = 42   | 题库的空、加载中、失败和长标题；题目不可用；家长空间未登录、会话出错、注册关闭；孩子登录；孩子注册；找回密码；缺少链接的重设密码和邮箱验证；404 |

页面测试的 `/api` 请求全部由测试固定回答，表里没有的请求让截图测试和可访问性检查都失败；时钟固定在 2026-11-07 10:00（北京时间）。长标题只是测试夹具，不进入题目清单。

## 可访问性检查和发现的问题

| 方面        | 检查                                                                                                                        | 发现的问题和处理                                                                                                                                                                                                                                                                   |
| ----------- | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| WCAG 2.2 AA | 每个 story 和每个页面状态运行 axe                                                                                           | 题库页“学习方式”的步骤编号 01–03 是 14px 的 `--teal`（#398271）文字，对比度约 4.4:1，低于 4.5:1。步骤编号使用 `--teal-dark`                                                                                                                                                        |
| 触摸        | 平板和手机视口里每个控件的宽和高都不小于令牌 `--touch-target`（2.75rem），也不小于 44 CSS 像素                              | 孩子登录“记住家庭码和昵称”的整行标签只有 32px 高，约十个独占一行的链接（如“请家长帮忙”“返回家长空间”“忘记密码？”“返回题库”）只有 20px 高。标签行至少 44px 高；独占一行的链接都使用共享的 `StandaloneLink`，宽和高至少 44px，孩子练习列表的链接占满整行；页头站名链接也至少 44px 高 |
| 键盘        | 桌面视口按 Tab 走完每个页面状态：每个控件可达（一组单选按钮算一站）、焦点轮廓至少 2px；跳转链接为第一站并把焦点移到主要内容 | 无                                                                                                                                                                                                                                                                                 |
| 减少动画    | 打开减少动画偏好后，没有元素带动画或过渡                                                                                    | 无                                                                                                                                                                                                                                                                                 |
| 缩放        | 320 CSS 像素宽、以及 640 像素宽加 200% 文字时不横向滚动                                                                     | 无                                                                                                                                                                                                                                                                                 |
| 不只靠颜色  | 9 个反馈状态在状态或提示区域里有文字                                                                                        | 无                                                                                                                                                                                                                                                                                 |

句子里的链接（如外部 AI 授权卡片里的数据保留说明）按 WCAG 的行内目标豁免，不要求 44px。Storybook 里只为演示加的按钮（画板的“检查导出”）不在页面上，触摸检查只量真实页面。

## 尚未验证

- 真机：手机和平板上的真实触摸、系统缩放、屏幕阅读器朗读、麦克风和声音，需要维护者在真机上补充确认。
- 登录后的家长空间和孩子空间只以组件 story 的形式截图，没有整页基准；整页需要真实账号数据，由端到端测试覆盖功能。
- 截图只在 Chromium 里生成；Safari 和 iPad 上的渲染差异由 #51 的真机验证覆盖。
