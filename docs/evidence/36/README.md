# #36 家长安排练习与儿童自由复习

已验证邮箱的家长在家长空间选择关联孩子，再从题库中选择已发布的题目。孩子登录后在「我的练习」打开安排的原版本，也可从题库自由选题或重做。安排按孩子、题目和版本保存，重复提交只保留一条。版本撤下后保留安排，显示不可用提示。正式题库内容随 #49 单独发布。

家长和儿童的读取都由服务端校验当前会话，读取分页，每页最多 20 条。家长写入还校验请求来源。测试题目仅存在于隔离测试注册表。迁移为新增表，删除孩子会级联清理安排。
