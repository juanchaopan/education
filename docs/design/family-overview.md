# 家长总览：每天的学习、学习时长和家庭时区

- 状态：AI 草稿，等维护者确认第二版样稿。规则是维护者 2026-11-12 在 [#164](https://github.com/juanchaopan/education/issues/164) 定下的，看过第一版样稿后的修改记在 [#164 记录](../evidence/164/README.md#维护者的意见)。
- 需求：REQ-005、REQ-009、REQ-002、REQ-011（都有 2026-11-12 的澄清）。变更原因见 [变更记录](../changes/2026-11-12-family-overview.md)。
- 涉及：`libs/contracts`；`apps/api` 的 `learning`（总览、每天的数字、一段时间的学习记录、学习计时）和 `identity`（家庭时区、注册、导出、删除）；`apps/web` 的家长空间（总览的孩子卡片、学习记录、「家庭」页）、题目页的计时和网站的白天晚上主题。「已安排」的书和进度照 [家长书架](bookshelf.md) 不变。

## 为什么要改

总览的孩子卡片现在只有按全部记录累计的题数和次数，网页要逐页读完每个孩子的整份学习记录再自己加。#138 的样稿里画的年级、分钟数和每天的柱子都没有数据来源。

之后：

- 每个孩子一张卡片，最上面是每天学习分钟的柱子：今天和它前面的 7 天，一共 8 根。柱子也是选择器：点一天，下面的数字只看这一天，再点一下回到 8 天。
- 往左能看更早的日子，边看边加载。
- 下面是这几天（或这一天）学了多少分钟，和一根按题分段的横条：做了几道题，其中独立完成、提示后完成、还没做出来各几道。
- 学习时长有真实的来源：孩子在题目页上动手学的时间。
- 每个家庭有自己的时区，一天从这个时区的 0 点算起；家里的页面也按它换白天和晚上的样子。时区和孩子、家庭码一起放在「家庭」页。
- 服务器一次给出总览要的数字，网页不再逐页读学习记录。

## 统计的规则

### 一天和看的日子

- **一天**从家庭时区的 0 点开始，到下一个 0 点结束。今天还没过完，数字算到现在。
- 卡片默认看**最近 8 天**：今天和它前面的 7 天，柱子下面依次写星期，今天写「今」。11 月 12 日周四看到的是 11 月 5 日到 11 月 12 日：四 五 六 日 一 二 三 今。
- **往前看**：每点一次「‹」往前挪 8 天（10 月 28 日到 11 月 4 日，再往前 10 月 20 日到 10 月 27 日……），各段首尾相接、不重叠；挪回来点「›」。触屏上也可以左右滑。翻到孩子最早有记录的那一段时，「‹」不能点。
- **选一天**：点一根柱子，数字只看这一天；再点同一根回到这 8 天。往前或往后挪时选择取消。

### 题怎么数

数的是**道**，不是次。一段时间（8 天或一天）里，孩子提交过作答或要过提示的每一道题（按题目 id，同一道题的几个版本算一道）正好归进下面一类，三类加起来就是「做了几道题」：

| 类         | 这段时间里                                               |
| ---------- | -------------------------------------------------------- |
| 独立完成   | 至少有一次独立完成                                       |
| 提示后完成 | 没有独立完成，至少有一次提示后完成                       |
| 还没做出来 | 作答过或要过提示，但没有完成（答错、判不出或只看了提示） |

- 一次作答算在它提交的那一天，一次提示算在要提示的那一天，都按家庭时区。所以同一道题在一天里是「还没做出来」，在包含第二天的 8 天里可能是「独立完成」。
- 提示后完成不算独立完成。数字只说做了什么，不说掌握了没有。
- 变化题（#217）的结果不进这些数；家长怎样看变化题由 #219 决定。

### 学习时长怎么计

- 只在**题目页**上计时：页面在前台可见，而且孩子在最近 2 分钟里动过手（点、按、拖、画、说话或打字）。别的页面、切到后台、锁屏、2 分钟没动手都不算。
- 计时由服务器根据心跳算：满足上面两个条件时，题目页每 30 秒发一次心跳，孩子从不动手到重新动手时马上发一次。服务器把这次心跳和这个孩子上一次心跳之间的时间加到今天（按家庭时区）的总数里；两次心跳隔了 90 秒以上，说明中间停过，这一段不算。
- 这样，重发的心跳和同时开着的两个标签页都不会多算，一天记下的时间不会超过墙上的钟走过的时间。断网时心跳发不出去，这段时间不算。
- 每个孩子每天存一个秒数，不存每次心跳。分钟按秒数除以 60 向下取整。这项功能上线以前的学习没有时长。

## 不加年级

#138 的样稿在孩子名字下面画了「一年级」，这是选风格时画的样子，没有哪项功能要用它。家长按书安排练习，书自己带着年级；孩子升了年级，去年的书照样留着，不需要孩子账号上再记一个年级。所以孩子账号不加年级，注册和总览都不问、不显示。

## 家庭时区

- 每个家庭存一个 IANA 时区名，例如 `Asia/Shanghai`。服务器只接受它认得的名字（`Intl` 能用来格式化时间的），长度不超过 64。
- **新家庭**：家长注册时网页带上浏览器的时区。注册请求里这一项可以没有，例如更新前打开的旧页面；没有时和已有家庭一样处理。
- **已有家庭**：迁移后时区是空的。空着的时候，服务器用配置里的默认时区 `DEFAULT_TIME_ZONE`（默认 `Asia/Shanghai`）。家长下一次打开家长空间时，网页发现家庭时区还空着，就把这台设备的时区填进去，不打扰家长。家长登录会长期保持，等「下次登录」可能要等几个月，所以不放在登录时做。
- **修改**：家长在「家庭」页的「家庭时区」卡片里修改。
- **用途**：统计按它分天；家里的页面按它换白天和晚上的样子（见下面「主题」）。

## 数据和迁移

迁移排在 #217 的迁移后面，编号按合并时的顺序取下一个。

| 表或列               | 内容                                                                                                                       |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `families.time_zone` | `text`，可空；空表示还没取到，按 `DEFAULT_TIME_ZONE` 算                                                                    |
| `study_days`         | 每个孩子每天的学习秒数：`child_id`（随孩子删除）、`day`（`date`，家庭时区的日子）、`seconds`（非负整数）；主键是孩子加日子 |
| `study_beats`        | 每个孩子上一次心跳的时刻：`child_id`（主键，随孩子删除）、`beat_at`。只用来算下一次心跳的间隔，不导出                      |

题的分类从现有的 `attempts`（每次作答的结果和提交时刻）和 `help_events`（每次提示的时刻）按天算出来，不另存。学习时长、作答和提示都保留到删除家庭；备份照常保留 14 天。

## 接口

一段时间的数字都是同一个形状：

```text
Problems = { independent, assisted, open }       // 三类各几道题，加起来是做了几道
Day      = { date, seconds, problems: Problems }
Range    = { from, to, seconds, problems: Problems }
```

### 家长：总览

`GET /api/v1/parents/overview`，家长会话。回答：

```text
{
  timeZone, today,                       // 家庭时区和它的今天，例如 '2026-11-12'
  children: [{
    id,
    days:  [Day],                        // 8 项，从早到晚，最后一项是今天
    range: Range,                        // 这 8 天合起来
    hasEarlier,                          // 更早还有没有作答、提示或学习时长
    review: [{ id, version, title, incorrect }]
  }]
}
```

- `children` 是家里的每个孩子，顺序和孩子列表一样；没有记录的孩子数字都是 0。
- `review` 是学习摘要标为建议复习的题（答错过、还没有独立完成），和现在「值得再练」的规则一样；题目清单里找不到的版本不列。
- 第一个 PR 先只给 `id`、按全部记录累计的 `total` 和 `review`，页面不变；学习时长的 PR 换成上面的形状。

### 家长：更早的日子

`GET /api/v1/parents/children/:childId/days?to=`，家长会话。`to` 是要看的 8 天的最后一天（`YYYY-MM-DD`）。回答 `{ days: [Day], range: Range, hasEarlier }`，`days` 是 `to` 和它前面的 7 天。`to` 不是合法日子或晚于今天：400；孩子不在这个家庭：404。

### 家长：一段时间的学习记录

`GET /api/v1/parents/children/:childId/learning?from=&to=`，家长会话，`from` 到 `to` 最多 8 天。回答：

```text
{ range: Range,
  items: [{ id, version, title, state, attempts, hints }],  // 这段时间做过的每道题
  total: { problems, seconds } }                             // 全部记录：做过几道题、一共学了多久
```

`state` 是上表的三类之一，`attempts` 和 `hints` 是这段时间里的作答和提示次数；独立完成在前，然后是提示后完成和还没做出来，同一类按题名。超过 8 天、`from` 晚于 `to` 或 `to` 晚于今天：400。

### 孩子：学习计时

`POST /api/v1/children/study-time`，孩子会话，请求体 `{}`，回答 204。按上面「学习时长怎么计」处理。没有孩子会话：401，页面停止发心跳。

### 家庭时区

- `GET /api/v1/parents/family/time-zone`：`{ timeZone, set }`，`set` 为 `false` 时 `timeZone` 是默认时区。
- `PUT /api/v1/parents/family/time-zone`：`{ timeZone }`，回答 204；名字不认得或有多余字段：400。
- `GET /api/v1/family/time-zone`：家长或孩子会话都能读，`{ timeZone }`，给网页决定主题用。孩子的登录和会话接口不变。
- 家长注册请求多一个可选的 `timeZone`，规则同上；名字不认得时当作没有。

## 家庭导出和删除

- 导出格式升一版（和 #217 同时合并时只升一次）。最外层加 `timeZone`（家庭时区，空着时写默认时区并注明）；每个孩子加 `studyTime: [{ date, seconds }]`，列出有学习时长的每一天，从早到晚。
- `familyExportScope` 的「包括」加上「家庭时区」和「每天的学习时长」；「不包括」加上「学习计时的心跳时刻」。
- 删除家庭时，`study_days` 和 `study_beats` 随孩子一起删除，家庭时区随家庭删除。删除卡片上的删除范围加上「每天的学习时长」。

### 总览的孩子卡片

每个孩子一张卡片，从上到下：

1. 头像和昵称。
2. **柱子**：8 列，每列是一个切换按钮（`aria-pressed`），整列都能点，没学的一天只有一道细线，上面照样留出空白可以点。柱高是这一天的学习分钟，按这 8 天里最多的一天定比例；柱子上不写数字，读屏读「11 月 5 日 12 分钟」。今天那一列的字写「今」，柱子和别的一样画，只换成强调色。选中的一列有浅底和厚度边，别的列的柱子变淡。左边一个圆形的「‹」按钮往前看；往前看过以后右边出现「›」往回看。这 8 天都没学时，柱子上方一行「这几天没有学习」，卡片其余部分照常。
3. **分钟**：一枚胶囊。8 天时写「11月5日 – 今天 已学 158 分钟」（往前看时是「10月28日 – 11月4日 已学 67 分钟」）；选了一天写「2026年11月12日 已学 12 分钟」。今天学了多少点「今」就能看到，不另写一行。
4. **题**：一行字「9 道题：独立完成 6 道 · 提示后完成 2 道 · 还没做出来 1 道」（是 0 的类不写），下面一根横条，按三类的道数分段，颜色和字前的圆点对应。没有题时写「没有做题」（选了一天时「这一天没有做题」），横条是空的。
5. 右下角「看学习记录」，去这个孩子的学习记录，带上卡片现在看的日子：选了一天就是这一天，否则是这 8 天。

其他状态：正在读取时是柱子、胶囊和横条的骨架；没读出来时一行「学习记录没有读出来。」和「重试」。卡片上不安排书。

「值得再练」「已安排」不变。底部的设置列表把原来没有的「家庭」加在 AI 老师下面，右边小字「孩子、家庭码、时区」，去「家庭」页。

### 学习记录（`/family/learning`）

1. 最上面一行选孩子，和书架上选孩子的一行同样的胶囊，换掉现在的下拉框。
2. **这段时间**卡片：地址里 `?child=<id>&from=<日子>&to=<日子>`，从总览过来时就是卡片看的日子；直接打开时是最近 8 天。标题是日子（一天写「2026年11月12日 周四」，8 天写「11月5日 – 今天」）；看一天时右边有「看这 8 天」，换成包含这一天的 8 天。下面是分钟胶囊、题的横条，再下面列出这段时间做过的每道题：题名，「作答 2 次 · 提示 0 次」，右边是这道题这段时间的类（独立完成、提示后完成、还没做出来的徽章）。
3. **学习摘要**卡片：最上面一行全部记录的累计「一共做过 38 道题 · 学了 6 小时 20 分」（不到 1 小时写「45 分钟」），下面是现在每道题的摘要，内容不变。

第一版样稿里学习记录的「前 7 天 / 后 7 天」翻页去掉了，往前看在总览的柱子上做；那一版的「一共」累计搬到学习摘要卡片的第一行。

### 家庭（`/family/profile`）

侧栏和标签栏的「孩子」改名「家庭」，地址从 `/family/children` 换成 `/family/profile`，旧地址转过来。这一页是家庭的资料：

1. **孩子**：每个孩子一行和「重置 PIN」，不变。
2. **家庭码**：大字的家庭码和复制按钮，一行「孩子登录时填，不是注册 KEY。」。总览右上角的家庭码筹码照旧。
3. **孩子注册 KEY**：不变；总览的「邀请孩子」链到这里。
4. **家庭时区**：
   - 大字写时区的中文名（`Intl` 的 `longGeneric` 名称，例如「中国时间」），旁边小字「现在 20:15 · 晚上」。
   - 一句说明：「每天的学习从这个时区的 0 点算起，家里每个人的页面也按它的时间换白天和晚上的样子。」这是做决定要看的，保留。
   - 「时区」下拉框列出浏览器认得的全部时区，按 UTC 偏移再按名字排，每项写「UTC+08:00 中国时间 · Asia/Shanghai」。下面是「保存」，选的和现在一样时不能点。
   - 这台设备的时区和家庭不同时，多一块提示「这台设备在北美东部时间，现在 7:15。」和次按钮「改成北美东部时间」，点了把下拉框换成它，再点保存。
   - 保存时按钮不能点、圆点代替文字「正在保存」；保存好了标题右边出现「已保存」；没保存上时按钮右边一行「没保存上，再点一次。」。

### 主题

[视觉语言](visual-language.md) 的白天、晚上主题按**家庭时区**的钟点切换（6:00–18:00 白天），不再看设备的钟：

- 网页读到家庭时区（家长空间读家长的、孩子登录后读孩子所在家庭的）后，记在这台设备上；页面头部的首屏脚本用它决定第一屏的主题。
- 这台设备还没有登录过家长或孩子时（例如第一次打开孩子登录页），照旧看设备的钟。
- 题目页的画面本来就不跟着主题变，不受影响。

视觉语言和 REQ-011 里「按设备本地时间切换」的说法随家庭时区的 PR 一起改。

## 实现要点

- `learning/domain`：日子的计算（家庭时区的今天、8 天一段的起止、按时区把时刻归到日子）和题的分类都是不依赖数据库的纯函数。日子用 `Intl` 换算，不手写偏移，夏令时由它处理。
- 仓储一次查一个家庭全部孩子 8 天的作答、提示和学习时长，不按孩子或按天逐个查；按时区分天在 SQL 里用 `AT TIME ZONE` 做。
- 学习计时的事务锁住这个孩子的 `study_beats` 一行，再加到 `study_days`，并发的心跳排队，不多算。
- 网页的计时放在题目页的公共外壳里，所有题目共用，题目自己不写。
- 柱子往前看时用「更早的日子」接口按需加载，加载过的段留在缓存里；触屏左右滑和按钮走同一个状态。
- 主题的计算 `themeAt` 接一个时区参数；页面开着时每分钟检查一次，跨过切换时刻就换。

## 测试

- 单元：日子的计算（时区边界、夏令时那天、今天算到现在、8 天一段首尾相接）；题的分类，三类各一条例子，再加一道题跨两天的例子；心跳间隔（30 秒、正好 90 秒、91 秒、重复心跳、跨午夜）。
- 接口：三个家长接口的每个错误；家庭隔离；时区的读写和校验；注册带和不带时区。
- 数据库：两次并发心跳只加一次间隔；删除家庭后没有学习时长留下；导出包括时区和每一天。
- 页面：卡片的每个状态（默认、选一天、选没学的一天、往前看、没有学习、读取中、没读出来），学习记录的一天和 8 天，「家庭」页和时区卡片的每个状态（Storybook、视觉基准，白天和晚上，桌面和手机）；e2e 走一遍孩子学一会儿、家长在卡片上看到分钟并点开那一天。
