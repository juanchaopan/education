# 网站视觉语言：白天的手作工作台，晚上的暮光剧场

- 状态：已确认（维护者 2026-11-08 在 #138 的样稿中选定；题目页周边是维护者 2026-11-10 在 #143 的样稿中选定的 B「露珠」；结论板是维护者 2026-11-11 在 #181 的样稿中选定的烟色玻璃胶囊）。书卡、默认封面、书架一行和家长书架是维护者 2026-11-12 在 #179 的样稿中确认的。立体感和统一的按钮、登录首页、孩子首页「我的书」、题目页的提示和预览标记是维护者 2026-11-12 在 #221 的样稿中确认的。
- 需求：REQ-011；决策见 [ADR-0016](../adr/0016-visual-language.md)，样稿和截图见 [#138 记录](../evidence/138/README.md)、[#143 记录](../evidence/143/README.md)、[#181 记录](../evidence/181/README.md)、[#179 记录](../evidence/179/README.md) 和 [#221 记录](../evidence/221/README.md)。
- 适用范围：网站外壳、首页、孩子和家长的页面、题目页周边的部件。题目画面本身（绘景、道具、分镜）和嵌在画面里的控件的摆放按 [课堂公共部件与绘景库](lesson-kit.md) 和逐题设计，不在这里规定。

## 为什么要统一

题目页是暖色灯光下的手作场景：木桌、黏土般圆润的物件、柔和的景深。网站其他页面却是浅色底、细边框、大段说明文字，像一个测试用的应用，孩子从首页走进题目像换了一个网站。视觉语言让两边用同一套颜色、材质、光感和形状。

## 两套主题，按家庭时区的钟点切换

|            | A 手作工作台（白天）     | B 暮光剧场（晚上）                     |
| ---------- | ------------------------ | -------------------------------------- |
| 时间       | 家庭时区 6:00–18:00      | 18:00–次日 6:00                        |
| 底色       | 暖米色纸张，带细微纸纹   | 深墨绿夜色，左上暖金、右上淡紫的灯光晕 |
| 卡片       | 象牙白，纸纹，暖棕色柔影 | 半透明深绿玻璃，金色细边，背景模糊     |
| 主色       | 森林绿按钮，奶白文字     | 暖金按钮，深棕文字，带光晕             |
| 点缀       | 蜂蜜黄、陶土橙           | 薄荷青、淡紫                           |
| 呼应的绘景 | 菜园、画室               | 模型工作室、片名卡出现时的暗场         |

规则：

- 两套主题只换颜色、底纹、阴影和光晕，**版式、字体、圆角、图标、动效完全相同**，所以切换不会让页面跳动。
- 钟点按**家庭时区**算（[家长总览](family-overview.md#主题)）：家长和孩子登录后，网页读到家庭时区并记在这台设备上；这台设备还没登录过家长或孩子时，按设备本地时间。家庭时区存的是 IANA 时区名，拨钟那天照样是当地 6:00 和 18:00 切换。
- 在首次渲染前按记下的家庭时区（没有时按设备本地时间）决定主题，页面开着时每分钟看一次钟，跨过切换时刻就换，颜色在 1.2 秒内过渡；打开「减少动态效果」时直接切换。
- 切换时刻写在一个配置常量里（`apps/web/src/shared/lib/day-night.ts`），不散落在组件中；页面头部的首屏脚本也由它生成。家长不需要也不能手动选择（以后需要时再加，不影响令牌结构）。
- **题目页整页不跟着白天和晚上切换。** 跟着时间换主题的只有题目页以外的页面：网站外壳、首页、孩子和家长的登录与注册、家长空间。题目页的画框里，画面用绘景自己的配色（片名卡、开始按钮、光晕和暗角都从题目定义的配色取）；画面上的一切控件，包括返回、「预览」标记、工具组、结论板、字幕、话筒、文字框、作答胶囊、提示露珠、提示条和提示条里的按钮、返回时的「正在保存」，以及没登录、书没安排、书暂时不可用时的提示卡，都是烟色玻璃，只用 `--dew-*` 令牌，任何时候看起来都一样。这样同一道题白天和晚上打开是同一幅画，深色的玻璃在亮的和暗的绘景上都看得清。

## 设计令牌

令牌放在 `apps/web/src/styles/tokens.css`，`:root[data-theme='day']` 和 `:root[data-theme='night']` 各一组，组件只引用令牌名。题目页的控件只用 `:root` 上那一组与主题无关的 `--dew-*`，不引用随主题变化的令牌。

| ----------------------------------------------------------------- | --------------------------------------------- | ----------------------------------------------- | ---------------------------------------------------- |
| `--bg`                                                            | `#f3eada` + 纸纹                              | `#13201e` + 灯光晕                              | 页面底色                                             |
| `--surface`                                                       | `#fffaf1`                                     | `rgba(32,50,47,.78)`                            | 卡片                                                 |
| `--surface-2`                                                     | `#f6ecdb`                                     | `rgba(255,240,210,.06)`                         | 输入框、分段、统计块                                 |
| `--ink` / `--ink-soft`                                            | `#33281d` / `#735f4b`                         | `#f6ead2` / `#b7aa90`                           | 正文 / 次要文字                                      |
| `--line`                                                          | `#e5d5bb`                                     | `rgba(246,222,170,.16)`                         | 边框、分隔                                           |
| `--primary` / `--primary-hi` / `--primary-edge` / `--primary-ink` | `#2f6e52` / `#3a7b5c` / `#1d4a36` / `#fff8ea` | `#f2c35b` / `#ffd77e` / `#a8791f` / `#2a1d08`   | 主按钮的面、高光、厚度边、文字                       |

| `--danger` / `--ok`                                               | `#b8492f` / `#3d8a5a`                         | `#f0896e` / `#8fe0a8`                           | 删除、出错 / 成功                                    |

## 字体

- 标题、数字、品牌：霞鹜文楷（LXGW WenKai，SIL OFL 1.1）的 700 字重，自己托管，按网站界面和题目标题实际用到的字子集化，构建时生成，不从境外字体服务加载。子集由 `apps/web/vite/title-font.ts` 在构建和开发服务启动时生成：取 `apps/web/src` 里除测试外所有源码中的中文字和题目清单的标题、年级、学科、分类，加上可打印的 ASCII；许可证随产物发布在 `/fonts/LXGW-WenKai-OFL.txt`。昵称等运行时才出现的字不在子集里，逐字回退到系统楷体。题目页的字幕、提问文字、结论板上的数字和「我听到 9 根」也用这套标题字体，像电影字幕。
- 正文和按钮：系统黑体（PingFang SC、Microsoft YaHei、Noto Sans CJK SC）。
- 字体加载失败时标题回退到系统楷体，再回退到黑体，版式不依赖字宽。

## 图标

- 自己画的一套 SVG 图标，24 格、2px 圆头描边，放在 `shared/ui/icons.tsx`，不引入图标库依赖。#138 样稿里已有的图标（返回、播放、麦克风、重听、提示、星星、钥匙、日历、盾牌、下载、删除、复制等）是第一批；#143 加了题目页的字幕开关、声音开关、发送、关闭、暂停、停止和「重说」（转圈箭头里的麦克风）；#179 加科目图标（数学的四个运算号、语文翻开的书、英语对话气泡里的 Aa、其他科目一本合上的书）和书架一行的书库（一排立着的书）、我的家庭（房子里一个人）两个图标，用在科目筹码、默认封面和书架一行上；#221 加眼睛（预览）、退出、向下和向上的箭头。新科目的图标在导入题目时由 agent 按这套风格画，维护者看截图确认。
- 题目画面里少数图标没有合适的线条画，由部件自己画成小插画，例如萤火虫提示里的萤火虫、答对时的实心星星；结论板上的道具小图就是题目画面里的道具本身，由题目给出。
- 不用表情符号或文字符号（✳、⌂）代替图标。
- 只有图标的按钮必须有读屏标签；图标旁的文字能省就省，但家长页的设置项保留文字。

## 立体感和统一的按钮

整个网站和课堂的画面一样有立体感（#221）：

- **页面顶上是有景深的画**：登录页一半是画、角色站在里面；孩子首页顶上是一条矮的画，「我的书」卡片压在它的下沿，小兔站在卡片后面探出头。画只给景深，不占孩子要用的地方。
- **能按的东西是同一种凸起**：一层纸色或主色的面、下面一道 3px 的深色边、一层柔和的投影；按下时往下沉 2px、边变成 1px；不能按（加载中、暂时不可用的书里的题）时变平，没有边和投影。课堂里的按钮可以更大，课堂以外的按钮彼此一样：

  | 级别         | 用在哪里                                                     | 尺寸                          |
  | ------------ | ------------------------------------------------------------ | ----------------------------- |
  | 课堂里的露珠 | 题目页的返回、提示、话筒、开始短片                           | 52px 以上，烟色玻璃           |
  | 主按钮       | 每页最要紧的一步：登录、「去登录」、「回到我的书」           | 高 48px，主色                 |
  | 次按钮       | 「加载更多」、「再试一次」                                   | 高 48px，纸色                 |
  | 筹码         | 筛选、登录页签的滑块                                         | 高 44px，选中主色、没选中纸色 |
  | 卡片和列表块 | 孩子首页的书、书里的题和展开按钮行、头像菜单里的「退出登录」 | 每行高 54–56px，纸色          |

- **输入框和进度条的槽是凹下去的**：内侧上沿一道浅投影。
- **书是立体的**：封面往里转一点角度，左边一道书脊的明暗，右边露出书页的边。
- **画面上的字和按钮是烟色玻璃**：顶栏的品牌和头像、题目页的提示卡用 `--dew-*` 令牌，和课堂里的控件一样。
- 打开「减少动态效果」时只去掉动效，凸起、投影和景深都保留。

家长空间按同样的做法改版是后续工作。

## 页面版式

## 文字原则

1. **能用控件、图标或状态表达的不写句子。** 例如格式说明交给输入框本身，复制成功用提示条。
2. **加载用动画**，「正在……」只给读屏。
3. **口号和安慰语删掉**（「慢慢来」「陪伴每一次尝试」、首页的介绍卡、页脚两句）。友好感由画面、角色和动效表达。
4. **隐私、安全、不可撤回、授权和数据范围必须说**，放在做决定的那一步（确认框、按钮旁），一到两句。
5. **次要细节折叠**到「?」详情里，例如邮件重试规则、链接有效期。
6. **出错说一句发生了什么，再给一个按钮**（重试、返回）。
