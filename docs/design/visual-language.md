# 网站视觉语言：白天的手作工作台，晚上的暮光剧场

- 状态：已确认（维护者 2026-11-08 在 #138 的样稿中选定）。
- 需求：REQ-011；决策见 [ADR-0016](../adr/0016-visual-language.md)，样稿和截图见 [#138 记录](../evidence/138/README.md)。
- 适用范围：网站外壳、题库、孩子和家长的页面、题目页周边的部件。题目画面本身（绘景、道具、分镜）按 [课堂公共部件与绘景库](lesson-kit.md) 和逐题设计，不在这里规定。

## 为什么要统一

题目页是暖色灯光下的手作场景：木桌、黏土般圆润的物件、柔和的景深。网站其他页面却是浅色底、细边框、大段说明文字，像一个测试用的应用，孩子从题库走进题目像换了一个网站。视觉语言让两边用同一套颜色、材质、光感和形状。

## 两套主题，按本地时间切换

|            | A 手作工作台（白天）     | B 暮光剧场（晚上）                     |
| ---------- | ------------------------ | -------------------------------------- |
| 时间       | 设备本地时间 6:00–18:00  | 18:00–次日 6:00                        |
| 底色       | 暖米色纸张，带细微纸纹   | 深墨绿夜色，左上暖金、右上淡紫的灯光晕 |
| 卡片       | 象牙白，纸纹，暖棕色柔影 | 半透明深绿玻璃，金色细边，背景模糊     |
| 主色       | 森林绿按钮，奶白文字     | 暖金按钮，深棕文字，带光晕             |
| 点缀       | 蜂蜜黄、陶土橙           | 薄荷青、淡紫                           |
| 呼应的绘景 | 菜园、画室               | 模型工作室、片名卡出现时的暗场         |

规则：

- 两套主题只换颜色、底纹、阴影和光晕，**版式、字体、圆角、图标、动效完全相同**，所以切换不会让页面跳动。
- 在首次渲染前按设备本地时间决定主题，页面开着时到点切换，颜色在 1.2 秒内过渡；打开「减少动态效果」时直接切换。
- 切换时刻写在一个配置常量里（`apps/web/src/app/theme/schedule.ts`），不散落在组件中；页面头部的首屏脚本也由它生成。家长不需要也不能手动选择（以后需要时再加，不影响令牌结构）。
- 题目页的画面不跟着切换，只有画面外的部件（返回、字幕、提问作答区）用当前主题。

## 字体

- 标题、数字、品牌：霞鹜文楷（LXGW WenKai，SIL OFL 1.1）的 700 字重，自己托管，按网站界面和题目标题实际用到的字子集化，构建时生成，不从境外字体服务加载。子集由 `apps/web/vite/title-font.ts` 在构建和开发服务启动时生成：取 `apps/web/src` 里除测试外所有源码中的中文字和题目清单的标题、年级、学科、分类，加上可打印的 ASCII；许可证随产物发布在 `/fonts/LXGW-WenKai-OFL.txt`。昵称等运行时才出现的字不在子集里，逐字回退到系统楷体。
- 正文和按钮：系统黑体（PingFang SC、Microsoft YaHei、Noto Sans CJK SC）。
- 字体加载失败时标题回退到系统楷体，再回退到黑体，版式不依赖字宽。

## 图标

- 自己画的一套 SVG 图标，24 格、2px 圆头描边，放在 `shared/ui/icons.tsx`，不引入图标库依赖。#138 样稿里已有的图标（返回、播放、麦克风、重听、提示、星星、钥匙、日历、盾牌、下载、删除、复制等）是第一批。
- 不用表情符号或文字符号（✳、⌂）代替图标。
- 只有图标的按钮必须有读屏标签；图标旁的文字能省就省，但家长页的设置项保留文字。

## 页面版式

- **孩子顶栏**：左边品牌，中间「探索」「星星」两个标签，右边孩子头像和退出图标。没有长导航。
- **题库首页**：顶部一张大横幅，用孩子上次那道题的绘景，叠一句问候和「继续」卡片；下面年级分段、科目筹码，再下面按分类排的题目卡（桌面三列，手机一列）。
- **孩子登录和注册**：一半是绘景和小兔，一半是卡片；手机上绘景在上、卡片压在下沿。表单只有输入框、PIN 方格、开关和一个主按钮，两条图标链接（第一次来、请家长帮忙）。
- **家长空间**：桌面左侧导航（总览、孩子、练习安排、学习记录、隐私与数据），手机改为底部悬浮标签栏。总览页依次是：家庭码筹码和「邀请孩子」、每个孩子一张卡片（本周题数、独立完成、分钟数、七天柱状图）、「值得再练」和「已安排」两栏、设置列表（AI 老师、导出、删除家庭）。
- **账号页面**（家长登录、注册、验证、找回密码）：和孩子登录同样的半图半卡片版式。
- **题目页周边**：左上玻璃返回按钮，顶部居中剧场名和题名，右上重听和字幕开关；字幕是带讲课角色头像的玻璃胶囊；画面下方一条作答栏：麦克风、「我听到 9 根」和确认、重说，以及带剩余次数的提示按钮。
- **网站外壳**：没有页脚口号。顶栏左边品牌，中间是孩子的入口（探索题目、孩子空间、孩子注册）组成的图标胶囊，右边单独放家长空间；放不下文字时（手机竖屏、超大字号）只显示品牌块和图标，文字留给读屏。孩子顶栏的「星星」、头像和退出随 #141 的孩子页面加入。题目页不带外壳（#133）。

## 文字原则

1. **能用控件、图标或状态表达的不写句子。** 例如格式说明交给输入框本身，复制成功用提示条。
2. **加载用动画**，「正在……」只给读屏。
3. **口号和安慰语删掉**（「慢慢来」「陪伴每一次尝试」、首页的介绍卡、页脚两句）。友好感由画面、角色和动效表达。
4. **隐私、安全、不可撤回、授权和数据范围必须说**，放在做决定的那一步（确认框、按钮旁），一到两句。
5. **次要细节折叠**到「?」详情里，例如邮件重试规则、链接有效期。
6. **出错说一句发生了什么，再给一个按钮**（重试、返回）。

### 现有文字的处理

「删」：去掉；「图」：改成图标、状态或控件；「折」：折叠到详情；「留」：保留，可缩短。加载提示一律按原则 2，不再逐条列出。
