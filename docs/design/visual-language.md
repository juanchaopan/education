# 网站视觉语言：白天的手作工作台，晚上的暮光剧场

- 状态：已确认（维护者 2026-11-08 在 #138 的样稿中选定；题目页周边 2026-11-10 在 #143 的样稿中改为 B「露珠」）。
- 需求：REQ-011；决策见 [ADR-0016](../adr/0016-visual-language.md)，样稿和截图见 [#138 记录](../evidence/138/README.md) 和 [#143 记录](../evidence/143/README.md)。
- 适用范围：网站外壳、题库、孩子和家长的页面、题目页周边的部件。题目画面本身（绘景、道具、分镜）和嵌在画面里的控件的摆放按 [课堂公共部件与绘景库](lesson-kit.md) 和逐题设计，不在这里规定。

## 为什么要统一

题目页是暖色灯光下的手作场景：木桌、黏土般圆润的物件、柔和的景深。网站其他页面却是浅色底、细边框、大段说明文字，像一个测试用的应用，孩子从题库走进题目像换了一个网站。视觉语言让两边用同一套颜色、材质、光感和形状。

## 两套主题，按本地时间切换

|            | A 手作工作台（白天）     | B 暮光剧场（晚上）                     |
| ---------- | ------------------------ | -------------------------------------- |
| 时间       | 设备本地时间 6:00–18:00  | 18:00–次日 6:00                        |
| 底色       | 暖米色纸张，带细微纸纹   | 深墨绿夜色，左上暖金、右上淡紫的灯光晕 |
| 卡片       | 象牙白，纸纹，暖棕色柔影 | 半透明深绿玻璃，金色细边，背景模糊     |
| 主色       | 森林绿按钮，奶白文字     | 暖金按钮，深棕文字，带光晕             |
| 点缀       | 蜂蜜黄、陶土橙           | 薄荷青、淡紫                           |
| 呼应的绘景 | 菜园、画室               | 模型工作室、片名卡出现时的暗场         |

规则：

- 两套主题只换颜色、底纹、阴影和光晕，**版式、字体、圆角、图标、动效完全相同**，所以切换不会让页面跳动。
- 在首次渲染前按设备本地时间决定主题，页面开着时到点切换，颜色在 1.2 秒内过渡；打开「减少动态效果」时直接切换。
- 切换时刻写在一个配置常量里（`apps/web/src/app/theme/schedule.ts`），不散落在组件中；页面头部的首屏脚本也由它生成。家长不需要也不能手动选择（以后需要时再加，不影响令牌结构）。
- 题目页的画面不跟着切换。嵌在画面里的露珠、字幕和胶囊属于画面，用烟色玻璃（`--dew-*` 令牌），两套主题下相同；画面上的提示条里的按钮用当前主题的按钮。

## 设计令牌

令牌放在 `apps/web/src/styles/tokens.css`，`:root[data-theme='day']` 和 `:root[data-theme='night']` 各一组，组件只引用令牌名。

| ----------------------------------------------------------------- | --------------------------------------------- | ----------------------------------------------- | ------------------------------ |
| `--bg`                                                            | `#f3eada` + 纸纹                              | `#13201e` + 灯光晕                              | 页面底色                       |
| `--surface`                                                       | `#fffaf1`                                     | `rgba(32,50,47,.78)`                            | 卡片                           |
| `--surface-2`                                                     | `#f6ecdb`                                     | `rgba(255,240,210,.06)`                         | 输入框、分段、统计块           |
| `--ink` / `--ink-soft`                                            | `#33281d` / `#735f4b`                         | `#f6ead2` / `#b7aa90`                           | 正文 / 次要文字                |
| `--line`                                                          | `#e5d5bb`                                     | `rgba(246,222,170,.16)`                         | 边框、分隔                     |
| `--primary` / `--primary-hi` / `--primary-edge` / `--primary-ink` | `#2f6e52` / `#3a7b5c` / `#1d4a36` / `#fff8ea` | `#f2c35b` / `#ffd77e` / `#a8791f` / `#2a1d08`   | 主按钮的面、高光、厚度边、文字 |

| `--danger` / `--ok`                                               | `#b8492f` / `#3d8a5a`                         | `#f0896e` / `#8fe0a8`                           | 删除、出错 / 成功              |
| `--shadow` / `--shadow-lift`                                      | 暖棕柔影                                      | 深影 + 金色光晕                                 | 静止 / 浮起                    |
| `--dew-*`                                                         | 烟色玻璃、绿、蜜黄、陶土红、金色角标和纸色    | 同左                                            | 嵌在题目画面里的露珠和字幕     |
| `--radius` / `--radius-lg`                                        | 16px / 26px                                   | 同左                                            | 输入框 / 卡片                  |

## 字体

- 标题、数字、品牌：霞鹜文楷（LXGW WenKai，SIL OFL 1.1）的 700 字重，自己托管，按网站界面和题目标题实际用到的字子集化，构建时生成，不从境外字体服务加载。子集由 `apps/web/vite/title-font.ts` 在构建和开发服务启动时生成：取 `apps/web/src` 里除测试外所有源码中的中文字和题目清单的标题、年级、学科、分类，加上可打印的 ASCII；许可证随产物发布在 `/fonts/LXGW-WenKai-OFL.txt`。昵称等运行时才出现的字不在子集里，逐字回退到系统楷体。题目页的字幕、提问文字和「我听到 9 根」也用这套标题字体，像电影字幕。
- 正文和按钮：系统黑体（PingFang SC、Microsoft YaHei、Noto Sans CJK SC）。
- 字体加载失败时标题回退到系统楷体，再回退到黑体，版式不依赖字宽。

## 图标

- 自己画的一套 SVG 图标，24 格、2px 圆头描边，放在 `shared/ui/icons.tsx`，不引入图标库依赖。#138 样稿里已有的图标（返回、播放、麦克风、重听、提示、星星、钥匙、日历、盾牌、下载、删除、复制等）是第一批；#143 加了题目页的字幕开关、声音开关、发送、关闭、暂停、停止和「重说」（转圈箭头里的麦克风）。
- 题目画面里少数图标没有合适的线条画，由部件自己画成小插画，例如萤火虫提示里的萤火虫、答对时的实心星星。
- 不用表情符号或文字符号（✳、⌂）代替图标。
- 只有图标的按钮必须有读屏标签；图标旁的文字能省就省，但家长页的设置项保留文字。

## 页面版式

- **孩子顶栏**：左边品牌，中间「探索」「星星」两个标签，右边孩子头像和退出图标。没有长导航。
- **题库首页**：顶部一张大横幅，用孩子上次那道题的绘景，叠一句问候和「继续」卡片；下面年级分段、科目筹码，再下面按分类排的题目卡（桌面三列，手机一列）。
- **孩子登录和注册**：一半是绘景和小兔，一半是卡片；手机上绘景在上、卡片压在下沿。表单只有输入框、PIN 方格、开关和一个主按钮，两条图标链接（第一次来、请家长帮忙）。
- **家长空间**（邮箱已验证的家长）：铺满整屏，不带网站顶栏。
  - 桌面左侧是侧栏：品牌、五个部分（总览、孩子、练习安排、学习记录、隐私与数据），底部是家长的头像、邮箱和退出图标。手机和竖放的平板上，品牌标、头像和退出在顶栏，五个部分改成底部悬浮标签栏。
  - 每个部分有自己的地址：`/family`、`/family/children`、`/family/practice`、`/family/learning`、`/family/privacy`。
  - 总览页依次是：家庭码筹码和「邀请孩子」（去孩子页的 KEY 卡片）；每个孩子一张卡片；「值得再练」和「已安排」两栏；设置列表（AI 老师带授权徽章、导出、删除家庭，分别去隐私与数据页的对应卡片）。
  - 孩子卡片只放现有接口有来源的数据：按全部记录累计的题数、独立完成次数和提示后完成次数，记录没读全时数字后加「+」。样稿里的年级、本周统计、分钟数和七天柱状图，等接口提供这些数据后再加。
  - 「值得再练」是学习摘要标为建议复习的题，可以直接安排。题目缩略图要等 #141 做出题目到绘景的查找后再加，现在用图标块。
  - 其余四个部分的每块内容都是带图标和标题的家长卡片。KEY 卡片先写 KEY 的状态和有效期；新生成的 KEY 放在一块亮色底的方块里，和复制按钮、安全提示在一起；「24 小时内有效、只能用一次，重新生成会撤销旧 KEY」写在按钮下一行。KEY 和 AI 授权的状态用状态徽章：KEY 还能用、服务已授权时是表示已办妥的 `--ok` 浅底，其余是表示还要家长处理的 `--accent-soft` 底。重置 PIN 和删除家庭的确认放在危险区里，用危险按钮，删除家庭的卡片描危险色边。学习记录把「当前记录不足以判断是否掌握」作为一行提示，统计方法折叠在「?」里。
- **账号页面**（家长注册、登录、邮箱验证、找回和重置密码、家庭已删除）：铺满整屏，不带网站顶栏。一半是绘景库里傍晚的画室和站在里面的小兔，一半是卡片，品牌放在卡片顶部、点它回首页；手机和竖放的平板上绘景在上、卡片压在下沿。卡片底部一行放去处（去登录或注册、忘记密码、返回家长空间）。邮箱没验证的家长登录后只看到验证卡片和退出。
- **题目页周边**（#143 的 B「露珠」）：短片占满整个屏幕，没有单独的控件区，所有控件都是嵌在画面边上的露珠。
  - 左上角是返回露珠；右上角是重听、字幕开关和声音开关三颗露珠；顶部居中留给结论板（#181），在那之前空着，题名只在片名卡上。
  - 小兔的话像电影字幕：一块烟色玻璃，左边是讲课角色的圆形头像，旁白、对提问的回答、作答时的「我听到你说……」和提示都在这一块里，新的一句替换旧的；旁白暂停时头像上出现蜜黄的播放角标，点它接着讲。
  - 右下角是陶土红的大话筒，按住提问；文字框在话筒旁边，松开后出现绿色的发送露珠，角上的 × 是不问了。
  - 作答那一幕，画面下方居中是作答胶囊（「我听到 9 根」、绿色的对、蜜黄的重说），旁边是装萤火虫的提示露珠，角标是剩下的次数。
  - 只在有意义的地方用颜色：对是绿，重说和再试是蜜黄，话筒是陶土红，其余是透明的烟色玻璃。
- **网站外壳**：没有页脚口号。顶栏左边品牌，中间是孩子的入口（探索题目、孩子空间、孩子注册）组成的图标胶囊，右边单独放家长空间；放不下文字时（手机竖屏、超大字号）只显示品牌块和图标，文字留给读屏。孩子顶栏的「星星」、头像和退出随 #141 的孩子页面加入。题目页不带外壳（#133），家长的账号页面和家长空间也不带，它们自带品牌（#142）；都保留「跳到主要内容」。

## 文字原则

1. **能用控件、图标或状态表达的不写句子。** 例如格式说明交给输入框本身，复制成功用提示条。
2. **加载用动画**，「正在……」只给读屏。
3. **口号和安慰语删掉**（「慢慢来」「陪伴每一次尝试」、首页的介绍卡、页脚两句）。友好感由画面、角色和动效表达。
4. **隐私、安全、不可撤回、授权和数据范围必须说**，放在做决定的那一步（确认框、按钮旁），一到两句。
5. **次要细节折叠**到「?」详情里，例如邮件重试规则、链接有效期。
6. **出错说一句发生了什么，再给一个按钮**（重试、返回）。

### 现有文字的处理

「删」：去掉；「图」：改成图标、状态或控件；「折」：折叠到详情；「留」：保留，可缩短。加载提示一律按原则 2，不再逐条列出。

| 页面或部件          | 文字                                                                                                   | 处理                                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| 网站外壳            | 页脚「慢慢想，每一步都算数。」「为好奇心，留一点空间。」                                               | 删                                                                                                          |
| 首页介绍（Welcome） | 「每一个『为什么』……」「小小的思考，大大的发现」、介绍卡和三条「把想法说出来」等                       | 删；换成问候和「继续」卡片                                                                                  |
| 题库                | 「从一个好问题开始」「一步一步，自由探索」、四级面包屑                                                 | 删                                                                                                          |
