# 变化题作答记录

逐幕探究的变化题怎样判、记什么、怎样导出。课堂上的做法（先猜、再动手、再说理由、最后揭晓）见手册的[逐幕探究](interactive-lesson-authoring.md#逐幕探究)；这里写服务端的规则、数据、接口和家庭导出。题目页怎样提交由 [#218](https://github.com/juanchaopan/education/issues/218) 做，家长摘要怎样显示由 [#219](https://github.com/juanchaopan/education/issues/219) 做，两者都按这里的接口和结果。

## 判定

只用题目作者写的规则判，模型不判对错。规则写在题目插件的 `variation` 里：

| 规则          | 判什么                                  | 结果                     |
| ------------- | --------------------------------------- | ------------------------ |
| `checkGuess`  | 孩子先猜的数，和最终作答一样的输入      | 对、错、无法判定         |
| `checkReason` | 孩子说的一句理由，或者点选的露珠        | 说清了、没说清、无法判定 |
| `hints`       | 变化题自己的 1–2 条萤火虫提示，按 id 取 | 提示的文字               |

- **猜的数。** 判出对错以后就锁定，这一轮不能再猜。判为无法判定（例如听成了「六根」这样的文字）时什么都不记、不锁定，请孩子再说一次。
- **理由。** 说出的和点选的按同一条规则判、一样记。说反了、只说了一半、说的不是这回事，都判为没说清，算答错；没说清以后孩子得到反馈和变化题的提示，可以再说，和最终作答答错以后一样。说清了以后理由锁定。判为无法判定时什么都不记，请孩子再说一次。
- **无法判定指没听出话来。** 通用的规则 `variationReason`：说的话去掉「嗯、啊、呃」这类声音以后不到两个字或数字，算无法判定，其余的都按题目的规则判为说清了或没说清；点选时一个也没点，或点了这道题没有的选项，算无法判定，正好点对「没变的」和「变了的」算说清了，其他点法算没说清。
- **帮助。** 变化题的提示和变化题作答时向老师提问，每一轮各记一次。判为对的猜数或说清了的理由，在它之前这一轮用过任何一次帮助，记为提示后答对或提示后说清。变化题的帮助只算在变化题上，不进最终作答的提示次数。

菜园题（「假如 1 个苹果 = 2 根黄瓜」）：猜 6 为对；理由要同时说出组数没变（还是三组）和每组的根数变了（每组两根），「还是三组，每组两根」「组数没变，根数变了」是说清了，「变成两组了」「每组还是三根」「一共六根」是没说清；露珠的选项是「组数」（`groups`）和「每组根数」（`per-group`），声明在课堂内容 `lessons/garden-balance.ts` 的 `gardenVariationChoices` 里，网站和插件都从那里读；提示是「数一数，现在有几组？每组有几根？」。

## 记在哪一轮

变化题记在最近一次最终作答答对的那一轮名下：最终作答答对时这一轮结束、换成新的一轮，变化题的请求带上刚结束的这一轮。孩子又答对一次以后，前一轮的变化题就不再收。还没答对过的题没有变化题可记。

## 数据

只存判定结果，不存孩子说的话、转写文字，也不存它们的摘要。两张表都随孩子删除（删除家庭时一起删除），保留期限和学习进度一样，到删除家庭为止；家长收回一本书时不删，再安排这本书时接着用。

**`variation_answers`**：每次判出结果的猜数和理由一行。

| 列                                          | 类型                                     | 说明                                                                       |
| ------------------------------------------- | ---------------------------------------- | -------------------------------------------------------------------------- |
| `child_id`、`problem_id`、`problem_version` | uuid、text、bigint                       | 哪个孩子的哪道题的哪个版本；`child_id` 随孩子级联删除                      |
| `attempt_id`                                | uuid                                     | 客户端为这次提交生成的 id，和前三列一起是主键                              |
| `round`                                     | uuid                                     | 记在哪一轮名下                                                             |
| `part`                                      | `guess` / `reason`                       | 猜数还是理由                                                               |
| `fingerprint`                               | text，猜数必填、理由为空                 | 猜的数（不是孩子的话）的带密钥摘要，用来分辨同一次提交的重试和换了数的提交 |
| `outcome`                                   | `independent` / `assisted` / `incorrect` | 独立答对（说清）、提示后答对（说清）、答错（没说清）；不存无法判定         |
| `submitted_at`                              | timestamptz，`clock_timestamp()`         | 判出结果的时间，一轮里的理由按它排先后                                     |

每一轮最多一个猜数（部分唯一索引 `variation_answers_one_guess`），最多一个说清了的理由（`variation_answers_one_clear_reason`）。

**`variation_help`**：变化题用过的帮助，每一轮每种一行，主键是孩子、题目、版本、轮和 `help_id`（提示的 id，或者提问时的 `teacher:question`），`requested_at` 记时间。

## 每一轮的结果

| 项         | 取值                                     | 怎样得出                                                         |
| ---------- | ---------------------------------------- | ---------------------------------------------------------------- |
| 猜数       | 独立答对、提示后答对、答错，或空（没猜） | 这一轮的猜数                                                     |
| 理由第一次 | 说清了、没说清，或空（没判出过）         | 这一轮最早判出的理由                                             |
| 理由最后   | 独立说清、提示后说清、没说清             | 最后判出的理由说清了就是它；没说清，或没说完理由就离开，是没说清 |
| 帮助       | 次数                                     | 这一轮 `variation_help` 的行数                                   |
| 开始、最后 | 时间                                     | 这一轮最早和最晚的一条记录                                       |

## 每道题的状态

一道题的所有变化题按下面的规则机械推出一个状态，不做掌握判断：

- 猜数和理由各自取所有轮里最好的结果：有一轮独立做到（猜数独立答对、理由独立说清）就是「独立做到」；否则有一轮提示后做到就是「提示后做到」；否则是「还没做到」。
- 「还缺」列出还没有独立做到的部分（猜数、理由）。
- 做到过一次就算做到，后来哪一轮做差了不改变状态；每一轮的结果都在明细里按时间列出。

## 接口

`GET /api/v1/problems/:id/:version/variation` 和 `POST` 同一路径，孩子登录后用，鉴权、来源检查、CSRF 和不缓存与最终作答的接口相同，请求体不超过 32 KB。

`GET` 回答 `{ round, guessed, explained }`：`round` 是最近一次答对的那一轮，还没答对过时为 `null`；`guessed` 表示猜数已经记下，`explained` 表示理由已经说清了。题目页刷新以后据此接着做。

`POST` 的请求，都带 `round`（上面的那一轮）：

| `action`   | 其他字段                                                                                                                                     | 回答                     |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| `guess`    | `attemptId`（uuid）、`input`（和最终作答相同的输入）                                                                                         | `{ attemptId, outcome }` |
| `reason`   | `attemptId`（uuid）、`reason`：`{ say }`（1–500 字）或 `{ choose: { kept, changed } }`（各最多 8 个不重复的选项 id，小写字母、数字和连字符） | `{ attemptId, outcome }` |
| `hint`     | `hintId`（小写字母、数字和连字符）                                                                                                           | `{ hint }`               |
| `question` | 无；孩子在变化题里向老师提问、问题发出之前先发这一条                                                                                         | `{ helped: true }`       |

`outcome` 是 `independent`（独立答对或独立说清）、`assisted`（提示后答对或提示后说清）、`incorrect`（答错或没说清）、`uncertain`（无法判定，什么都没记，请孩子再说一次）。猜数的结果给题目页用来决定是否请孩子再说，页面上只显示「记下了」，不说对错。

同一个 `attemptId` 重发时回答原来的结果，不重复记：猜数换了数、或者拿猜数的 id 交理由，回答 409；理由按 id 回答已记的结果，不再判一次，也不比对说的话。判为无法判定的提交没有记录，重发时重新判。

| 状态     | 什么时候                                   | 文字                                   |
| -------- | ------------------------------------------ | -------------------------------------- |
| 400      | 请求不符合上面的格式                       | 通用的格式错误                         |
| 401、403 | 没有登录、登录已失效，或请求不是从本站发出 | 和最终作答的接口相同                   |
| 404      | 这道题这个版本没有变化题                   | 这道题没有变化题。                     |
| 404      | 没有这条提示                               | 这条提示暂时不可用。                   |
| 409      | `round` 不是最近一次答对的那一轮           | 这一轮的变化题已结束，请重新打开题目。 |
| 409      | 这一轮已经记下猜数                         | 猜的数已经记下了。                     |
| 409      | 还没有猜数就交理由                         | 先猜一个数，再说理由。                 |
| 409      | 理由已经说清了                             | 理由已经记下了。                       |
| 409      | 同一个 id 换了内容                         | 这次提交的内容已变化，请重新提交。     |
| 503      | 服务没有配置                               | 暂时无法提交，请稍后重试。             |

同一道题的最终作答、草稿和变化题共用一把锁，两次猜数同时到达时只记一个。

## 家庭导出

导出格式升到 `version: 3`，每个孩子多一项 `variations`，每道做过变化题的题目一项，按题目 id 和版本排：

```text
variations: [{
  id, version, title,
  status: { guess, reason },        // independent | assisted | not-yet
  missing: ['guess' | 'reason'],    // 还没有独立做到的部分
  attempts: [{                      // 每一次变化题，按开始时间
    guess,                          // independent | assisted | incorrect | null
    reason: { first, final },       // first: clear | unclear | null；final: independent | assisted | unclear
    help, startedAt, updatedAt
  }]
}]
```

`familyExportScope` 的「包括」加上这一项，「不包括」加上孩子说的理由和它的转写文字。
