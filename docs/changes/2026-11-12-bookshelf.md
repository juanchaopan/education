# 家长书架：按书安排练习

- 日期：2026-11-12
- 级别：L2 需求变更（REQ-009 的安排单位、新题、进度和书的状态）；设计冲击 D2（练习安排的数据、接口和页面整组重做，题目定义改为引用书）
- 来源：[#179](https://github.com/juanchaopan/education/issues/179)；维护者 2026-11-12 的决定记在 [#179 的评论](https://github.com/juanchaopan/education/issues/179#issuecomment-6823300887)，看过样稿后的修改记在 [#179 记录](../evidence/179/README.md#维护者的选择)。

## 变了什么

之前家长在「练习安排」里一次安排一道题：在下拉框里选孩子，再从列出全部题目的下拉框里选一道。安排按「孩子 + 题目 + 固定版本」存，没有取消。

之后家长按书安排：

- 一本书是「年级 + 科目 + 分类」的一个组合，书名就是分类名，有不随改名变化的稳定 id、一个状态（可用或暂时不可用）和可选的封面。
- 家长书架分书库、我的家庭和每个孩子。在书库里挑书，安排给一个或几个孩子，这本书就进入我的家庭；选一个孩子时还能按已安排、未安排筛选。点一下就安排，再点一下就取消。
- 安排永久有效，没有期限和状态，也没有单题安排。孩子只能学安排给他的书（访问规则由 #221 实现）。
- 每个孩子在每本书上有 n / m 的进度，标在封面的角上，学完打勾。取消安排不清零。
- 书里以后加的题直接出现在孩子的练习里。

## 为什么

- 一次一道题，题目多了以后家长要点很多下；下拉框也和家长空间的其他部件不一样。
- 题目本来就按分类成组，家长和孩子都按「一本书」理解练习。
- 期限和状态让家长和孩子多一层要管的事；进度已经说明做到了哪里，所以维护者决定不要。
- 有的书可能因为版权等原因要暂时撤下，又不能让已经安排过的家庭找不到它。

## 决定

- 只有整本书的安排，不做单题安排，「值得再练」去掉安排按钮。
- 已有的单题安排在迁移时丢弃，不转成书的安排；旧表按先扩展后收缩处理，两个 PR 之间旧页面上新增的单题安排同样丢弃。
- 安排没有期限和状态；取消不弹确认框、也不需要撤销。
- 进度：书里的每道题，任何版本，有过独立完成或提示后完成就算做完；取消不清零，再安排接着原来的进度。
- 孩子只能学安排给他的书，没登录的访客看不到题；服务端拦截、公开首页和题目页的提示由 #221 做。#179 里孩子的「我的练习」只列安排的书。
- 书的 id 用可读短名，改名不变；书名就是分类名。
- 书有状态：可用或暂时不可用，写在书单里由维护者改，书单里的书不删除。暂时不可用的书不能新安排；家长和安排过它的孩子都看到置灰的书、写「暂时不可用」，孩子打不开书里的题，家长可以取消；没人安排过的看不到。
- 书架最上面单独一行：书库、我的家庭、每个孩子，默认书库，不写标签文字。书库只有还没安排给任何孩子的可用书；我的家庭有安排给孩子的书，封面右下角标每个孩子的进度；选一个孩子时进度在封面右上角，学完换成带勾的样子，筛选里多一组全部、已安排、未安排。书卡上不写「已做 n / m」那行字。
- 在书库和我的家庭里点「安排」一律弹出孩子列表，家里只有一个孩子时也一样；选一个孩子时按钮直接切换。
- 总览「已安排」按书单顺序、几个孩子轮流取，链到每个孩子书架上的「已安排」筛选。
- 还没有孩子时也能看书库，顶部放一张邀请卡。
- 封面竖版 3:4，768×1024 的 WebP，不超过 80 KB；风格和绘景一样，中间一个主体，不画字；没有封面时用科目色纸纹底、科目图标和年级字样。封面由维护者在 Codex 里生成，封面库放进仓库。导入 PDF 遇到新科目时，由 agent 按现有风格画科目图标、配底色，出截图给维护者确认。
- 书架上滑自动加载，每批 24 本，底部留「加载更多」作后备；筛选写进地址；不做按书名搜索；家长这次看不到书里的题目列表。
- 家庭导出带上导出时书的状态、进度和是否学完。
