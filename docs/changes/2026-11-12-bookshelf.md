# 家长书架：按书安排练习

- 日期：2026-11-12
- 级别：L2 需求变更（REQ-009 的安排单位、新题和进度）；设计冲击 D2（练习安排的数据、接口和页面整组重做，题目定义改为引用书）
- 来源：[#179](https://github.com/juanchaopan/education/issues/179)；维护者 2026-11-12 的决定记在 [#179 的评论](https://github.com/juanchaopan/education/issues/179#issuecomment-6823300887)。

## 变了什么

之前家长在「练习安排」里一次安排一道题：在下拉框里选孩子，再从列出全部题目的下拉框里选一道。安排按「孩子 + 题目 + 固定版本」存，没有取消。

之后家长按书安排：

- 一本书是「年级 + 科目 + 分类」的一个组合，书名就是分类名，有不随改名变化的稳定 id 和可选的封面。
- 家长在书架上按年级和科目筛选，选一个孩子，点一本书就安排上，再点一下就取消。
- 安排永久有效，没有期限和状态，也没有单题安排。
- 每个孩子在每本书上有「已做 n / m」的进度，学完打勾。进度只看作答记录，和安排无关。
- 书里以后加的题直接出现在孩子的练习里。

## 为什么

- 一次一道题，题目多了以后家长要点很多下；下拉框也和家长空间的其他部件不一样。
- 题目本来就按分类成组，家长和孩子都按「一本书」理解练习。
- 期限和状态让家长和孩子多一层要管的事；进度已经说明做到了哪里，所以维护者决定不要。

## 决定

- 只有整本书的安排，不做单题安排，「值得再练」去掉安排按钮。
- 已有的单题安排在迁移时丢弃，不转成书的安排；旧表按先扩展后收缩处理。
- 安排没有期限和状态；取消不弹确认框、也不需要撤销。
- 进度：书里的每道题，任何版本，有过独立完成或提示后完成就算做完，包括安排之前做的；取消不清零。
- 书的 id 用可读短名，改名不变；书名就是分类名。
- 封面竖版 3:4，768×1024 的 WebP，不超过 80 KB；风格和绘景一样，中间一个主体，不画字；没有封面时用科目色纸纹底、科目图标和年级字样。封面由维护者在 Codex 里生成，封面库放进仓库。
- 书架上滑自动加载，每批 24 本，底部留「再看 24 本」作后备；筛选写进地址；不做按书名搜索；家长这次看不到书里的题目列表。
- 家庭导出带上导出时的进度和是否学完。
