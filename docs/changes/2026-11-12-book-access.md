# 孩子只学安排的书，访客看不到题目

- 日期：2026-11-12
- 状态：草稿，待维护者确认需求文字、接口回答和样稿。
- 级别：L2 需求变更（REQ-001 浏览题库的对象，REQ-009 去掉自由复习）；设计冲击 D1（题目下面的接口先收拢到同一个「孩子 + 题目」入口，再加访问检查）
- 来源：[#221](https://github.com/juanchaopan/education/issues/221)。维护者 2026-11-12：「什么叫自由复习？应该没有这个东西的，只有家长给你安排过这本书，你才能够去学」；访客「什么都看不到」。

## 变了什么

之前首页是公开题库，访客和孩子都能浏览、打开任何题；访客能看完短片，只是不保存。REQ-009 的标题和验收里有「自由复习」，#141 写着「其他书可以自由复习」。题目详情和题库接口不看登录，作答、草稿和提问接口只看孩子登录，不看书有没有安排。

之后：

- 访客（包括只登录家长账号的浏览器）在首页只看到家长注册、登录和孩子登录的入口，打开题目链接只看到登录入口。
- 孩子只看到、只能打开安排给自己的书里的题；题库、题目详情、作答、草稿和 AI 接口都由服务端检查安排，没安排回答 403 `unassigned`，暂时不可用回答 403 `unavailable`。
- 暂时不可用的书在孩子的题库里置灰，题打不开。
- 孩子从题目链接登录后回到这道题。
