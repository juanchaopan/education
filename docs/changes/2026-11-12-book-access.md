# 孩子只学安排的书，访客看不到题目

- 日期：2026-11-12
- 状态：需求已由维护者确认并写进需求文档；页面和接口的设计等维护者看过样稿后确认。
- 级别：L2 需求变更（REQ-001 浏览题库的对象，REQ-009 去掉自由复习、加上做题模式和预览模式，REQ-010 返回的去处）；设计冲击 D1（题目下面的孩子接口先收拢到同一个「孩子 + 题目」入口，再加访问检查；课堂页面收到的会话从可有可无的 CSRF 改成做题模式或预览模式之一）
- 来源：[#221](https://github.com/juanchaopan/education/issues/221)。维护者 2026-11-12：「什么叫自由复习？应该没有这个东西的，只有家长给你安排过这本书，你才能够去学」；访客「什么都看不到」。看过两轮样稿后的决定见下面。

## 变了什么

之前首页是公开题库，访客和孩子都能浏览、打开任何题；访客能看完短片，只是不保存。REQ-009 的标题和验收里有「自由复习」，#141 写着「其他书可以自由复习」。题目详情和题库接口不看登录，作答、草稿和提问接口只看孩子登录，不看书有没有安排。孩子登录在 `/child`，家长登录在 `/family` 的注册页下面；孩子登录后的顶栏有四个入口，首页的题库和孩子空间的「我的练习」重叠。

之后：

- 首页对访客是登录页：孩子登录（默认）和家长登录两个页签。
- 孩子登录后首页就是自己的空间「我的书」：顶栏只有品牌和头像菜单（退出登录）；书可以按全部、在学、新安排、学完、暂时不可用筛选，家长新安排的书在「新安排」上用红点和数字提醒，孩子打开书里一道题后不再算新的；书里的题排满两行再放「还有 n 道」。`/child` 转到首页。
- 一道题有做题模式和预览模式。孩子只能以做题模式打开安排给自己的书里的题；打开一道题、作答、草稿、变化题和 AI 接口都由服务端检查安排，没安排回答 403 `unassigned`，暂时不可用回答 403 `unavailable`。家长以预览模式打开：课照常走、答案照常判、反馈和做题模式一样，什么都不记录，不调用 AI，画面上标着「预览」。公开题库接口删除。
- 孩子从题目链接登录后回到这道题。
- 本次画的页面都有和课堂画面一样的立体感：顶上一幅有景深的画，能点的东西凸起，书是立体的。

## 决定

- 首页是登录页，照家长账号页面的版式，孩子登录和家长登录两个页签，默认孩子登录；孩子登录仍用家庭码、昵称和六位 PIN，KEY 只用于注册。孩子注册、家长注册、找回密码的页面照现在的样子用。
- 孩子首页的书：没学完的在前、学完的在后，每组里最近学过（最近一次提交作答）的在前；从没学过的排在没学完一组最后、新安排的在前；暂时不可用的置灰放在最后。
- 孩子登录后的顶栏要从孩子真正需要的出发，尽量少；首页和孩子空间不能是两个列重叠内容的地方。
- 孩子首页要有筛选，家长新安排的书用红色实心圆里的数字提醒。
- 书里的题不留半空的行。
- 整个设计要有课堂画面那样的立体感；家长空间的改版另开 issue。
- 家长可以预览家长书架上所有可用的书：走完整节课、点选作答、按同样的规则判对错，什么都不保存，不用话筒、不向小兔提问、没有 AI 花费。标记只写「预览」，作答的反馈和做题模式一样。需求里写明做题模式和预览模式。
- 家长页面里的预览入口以后做（会和 #164 冲突），这次只能从题目链接进预览；预览是单独的第 5 个 PR。
- 题目链接登录后回到这道题，`next` 只接受站内题目地址。
- 题目页的提示分开：没登录只有登录提示；孩子没安排是「请家长安排这本书」；书撤下是「这本书暂时不可用」；家长是预览模式。
- 课堂静态文件这次不挡，挡住它们作为后续 issue。
- 还待维护者确认：样稿；筛选的组成和默认；新书什么时候不再算新。
