# 孩子只学安排的书，访客看不到题目

- 日期：2026-11-12
- 状态：草稿，待维护者确认需求文字、预览的细节和样稿。
- 级别：L2 需求变更（REQ-001 浏览题库的对象，REQ-009 去掉自由复习、加上家长预览，REQ-010 返回的去处）；设计冲击 D1（题目下面的孩子接口先收拢到同一个「孩子 + 题目」入口，再加访问检查；课堂页面收到的会话从可有可无的 CSRF 改成孩子或预览两种之一）
- 来源：[#221](https://github.com/juanchaopan/education/issues/221)。维护者 2026-11-12：「什么叫自由复习？应该没有这个东西的，只有家长给你安排过这本书，你才能够去学」；访客「什么都看不到」。看过第一版样稿后：首页改成登录页，照 `/family` 的样子分孩子登录和家长登录两个页签；孩子的书没学完的在前、学完的在后，每组里最近学过的在前；家长可以预览题目；题目链接登录后回到这道题；题目页按情况分开提示；课堂静态文件这次不挡，另开 issue。

## 变了什么

之前首页是公开题库，访客和孩子都能浏览、打开任何题；访客能看完短片，只是不保存。REQ-009 的标题和验收里有「自由复习」，#141 写着「其他书可以自由复习」。题目详情和题库接口不看登录，作答、草稿和提问接口只看孩子登录，不看书有没有安排。孩子登录在 `/child`，家长登录在 `/family` 的注册页下面。

之后：

- 首页对访客是登录页：孩子登录（默认）和家长登录两个页签。
- 孩子登录后首页是「我的书」，按没学完、学完、暂时不可用分组，组里按最近学习排。
- 孩子只能打开安排给自己的书里的题；打开一道题、作答、草稿、变化题和 AI 接口都由服务端检查安排，没安排回答 403 `unassigned`，暂时不可用回答 403 `unavailable`。公开题库接口删除。
- 家长打开题目是预览：课照常走、答案照常判，什么都不记录，不调用 AI。
- 孩子从题目链接登录后回到这道题。

## 决定

- 首页是登录页，照家长账号页面的版式，孩子登录和家长登录两个页签，默认孩子登录；孩子注册、家长注册、找回密码的页面照现在的样子用，改版由 #141 做。
- 孩子的书：没学完的在前、学完的在后，每组里最近学过的在前。
- 家长可以预览题目，什么都不记录。
- 题目链接登录后回到这道题，`next` 只接受站内题目地址。
- 题目页的提示分开：没登录只有登录提示；孩子没安排是「请家长安排这本书」；书撤下是「这本书暂时不可用」；家长是预览。
- 课堂静态文件这次不挡，挡住它们作为后续 issue。
- 其余待维护者确认的：需求文字；孩子登录的字段；从没学过的书的位置和「最近学习」怎么算；预览的范围、作答和入口；每张样稿；PR 的拆法。
