# 孩子只学安排的书，访客看不到题目

- 日期：2026-11-12
- 状态：需求已由维护者确认并写进需求文档；登录页、题目页和预览模式的样稿维护者已确认，孩子首页按第五轮意见重画，等维护者确认。
- 级别：L2 需求变更（REQ-001 浏览题库的对象，REQ-009 去掉自由复习、加上做题模式和预览模式、孩子首页的顺序和新书，REQ-010 返回的去处）；设计冲击 D1（题目下面的孩子接口先收拢到同一个「孩子 + 题目」入口，再加访问检查；课堂页面收到的会话从可有可无的 CSRF 改成做题模式或预览模式之一）
- 来源：[#221](https://github.com/juanchaopan/education/issues/221)。维护者 2026-11-12：「什么叫自由复习？应该没有这个东西的，只有家长给你安排过这本书，你才能够去学」；访客「什么都看不到」。看过五轮样稿后的决定见下面。

## 变了什么

之前首页是公开题库，访客和孩子都能浏览、打开任何题；访客能看完短片，只是不保存。REQ-009 的标题和验收里有「自由复习」，#141 写着「其他书可以自由复习」。题目详情和题库接口不看登录，作答、草稿和提问接口只看孩子登录，不看书有没有安排。孩子登录在 `/child`，家长登录在 `/family` 的注册页下面；孩子登录后的顶栏有四个入口，首页的题库和孩子空间的「我的练习」重叠。

之后：

- 首页对访客是登录页：孩子登录（默认）和家长登录两个页签。
- 孩子登录后首页就是自己的空间「我的书」：顶上一条矮的画，顶栏只有品牌和头像菜单（退出登录），书从屏幕上方不远处开始；新书排在最上面，「在学」筛选上的红点是新书的本数，孩子打开新书里的一道题后不再算新书；每本书是一块能展开的凸起卡片，最下面一整行「全部 n 道」，展开后一行一道列出书里的题，这一行移到最后变成「收起」；暂时不可用的书置灰，能展开看题但打不开；手机上滑到底自动加载，电脑上点「加载更多」。`/child` 转到首页。
- 一道题有做题模式和预览模式。孩子只能以做题模式打开安排给自己的书里的题；打开一道题、作答、草稿、变化题和 AI 接口都由服务端检查安排，没安排回答 403 `unassigned`，暂时不可用回答 403 `unavailable`。家长以预览模式打开：课照常走、答案照常判、反馈和做题模式一样，什么都不记录，不调用 AI，画面上标着「预览」。公开题库接口删除。
- 孩子从题目链接登录后回到这道题。
- 本次画的页面都有和课堂画面一样的立体感，课堂以外的按钮和部件是同一种凸起。

## 决定

- 首页是登录页，照家长账号页面的版式，孩子登录和家长登录两个页签，默认孩子登录；孩子登录仍用家庭码、昵称和六位 PIN，KEY 只用于注册。孩子注册、家长注册、找回密码的页面照现在的样子用。
- 孩子的顶栏只留品牌和头像菜单；首页就是孩子的空间。
- 孩子首页顶上只是一条矮的画，小兔从「我的书」卡片后面探头，没有问候语，书从屏幕上方不远处开始。
- 孩子首页：新书（还没打开过其中的题）排在最前面、新安排的在前；其余没学完的按最近学过（最近一次提交作答）排；然后是学完的；暂时不可用的置灰放在最后。筛选是全部（默认）、在学、学完和暂时不可用（只在有这样的书时出现），没有单独的「新安排」筛选，新书的本数用红色实心圆标在「在学」上。
- 孩子打开新书里的任意一道题后才不算新书，只展开题目列表不算；新书在服务器打开题目时消掉，不另设接口。
- 进度保留「5 / 12」的数字，用进度条表示。
- 每本书一块凸起的卡片，收起时整张卡片是一个展开按钮，最下面一整行「全部 n 道」，不露任何一道题；展开后所有屏幕一列、题名完整，这一行移到列表最后变成「收起」，整张卡片只有这一个「收起」；为手指设计，不用下拉框。
- 暂时不可用的书：「暂时不可用」和书名同一种灰色、正常字重，进度条变灰；能展开看题，题目打不开；列表里不再写一行理由；「全部 n 道」和「收起」照常能按，不变灰。
- 「我的书」每批 6 本，手机上滑到底自动加载，电脑上用凸起的「加载更多」按钮，有「加载中…」。
- 全站按钮和部件同一种有质感的立体样式，课堂里的可以更大，课堂以外的彼此一样；家长空间的改版另开 issue。
- 家长可以预览家长书架上所有可用的书：走完整节课、点选作答、按同样的规则判对错，什么都不保存，不用话筒、不向小兔提问、没有 AI 花费。标记只写「预览」，作答的反馈和做题模式一样。需求里写明做题模式和预览模式。
- 家长页面里的预览入口以后做（会和 #164 冲突），这次只能从题目链接进预览；预览是单独的第 5 个 PR。
- 题目链接登录后回到这道题，`next` 只接受站内题目地址。
- 题目页的提示分开：没登录只有登录提示；孩子没安排是「请家长安排这本书」；书撤下是「这本书暂时不可用」；家长是预览模式。
- 课堂静态文件这次不挡，挡住它们作为后续 issue。
