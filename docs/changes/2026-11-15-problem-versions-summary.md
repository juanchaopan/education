# 题目的版本和按题的学习摘要

- 日期：2026-11-15
- 级别：L2 需求变化；设计冲击 D2
- 来源：[#219](https://github.com/juanchaopan/education/issues/219)。维护者 2026-11-15 看过 #219 的样稿（[#219 记录](../evidence/219/README.md)）后提出新的方向：学习摘要按题列、结果只分三种、另有按版本的详情；题目出了新版本时孩子的进度不受影响，打开时问要不要试新版本。

## 变了什么

改动前，孩子的书里每道题一律打开最新版本；题目出了新版本，孩子下次打开就是新版本，做到一半的课换成新的一节。家长的学习摘要一个版本一行，列独立完成、提示后完成、提示、答错和无法判定五个次数，同一道题的几个版本各占一行；#219 打算在每行下面再加一行变化题的结果和轮数。

改动后，孩子在每道题上有自己的版本：做过的最高版本。出了新版本，不点进题目时什么都不变；做过旧版本的孩子每次打开都被问「这道题有新版本了，要试试吗？」，可以试新版本，也可以接着做原来的；没做过的孩子直接打开最新版本。家长的学习摘要按题列，每道题一项，显示孩子做过的最大版本的结果，只分独立完成、提示后完成、还没完成，不列次数；原题看最终答案，逐幕探究的变化题分猜数和理由。点进一道题是按版本的详情：全部版本，包括没做过的和已下架但有记录的。两页显示什么按课堂流程设计，手册把它写成设计新流程时必须定下的一项。

## 为什么

- 一行一个版本，家长要自己对哪几行是同一道题；五个次数说不清孩子做到了没有。#219 的样稿里同一格有三套近义的词、两个容易混的「次」，手机上一个版本占很高一格（见 [#219 记录](../evidence/219/README.md#样稿里看出的几处)）。
- 新版本直接替换，会让做到一半的课突然换掉，做完的题在新版本上看起来又没做。
- 不同的课堂流程留下的证据不一样，摘要不能只按逐幕探究设计。

## 决定

维护者 2026-11-15 定下的：

- 定级 L2 + D2；拆成重构 → 孩子选版本 → 按题的学习摘要（接替 #219）→ 按版本的详情页。
- 孩子这边：新版本不改孩子的进度，不点进题目时什么都不变。做过旧版本的孩子每次打开这道题都被问「这道题有新版本了，要试试吗？」，直到选了新版本；只说「新版本」，不说「版本二」；孩子可以留在原来的版本，做到一半的也一样。没做过这道题的孩子直接打开最新版本，不问。
- 按题的摘要：每道题一项，显示孩子做过的最高版本；孩子答应试新版本以后，即使旧版本做完了也显示新版本，新版本做到一半显示还没完成。
- 结果只有三种：独立完成、提示后完成、还没完成，不列次数。原题看最终答案；变化题分猜数和理由，各是三种之一。胶囊是 #219 样稿的 B：绿、蜜黄、素色。
- 按版本的详情页：从一道题点进去，列出全部版本，包括没做过的；没做过写「没做过」，和还没完成是两种样子；已下架但有记录的版本列出来并标「已下架」；每个版本分别显示原题和变化题。
- 按流程：两页显示什么按课堂流程设计（逐幕探究有原题和变化题，别的流程不同）；手册写明设计新的流程时要决定它在学习摘要里按题和按版本怎样显示。

取的默认（维护者可以改）：

- 「做过一个版本」指在上面作答过、要过提示或在作答时向老师提问、交过变化题的猜数或理由，或者选过这个版本。
- 一个版本里的结果取做到过的最好结果（做到过一次就算做到），和变化题记录的规则一样。
- 「值得再练」和「建议复习」仍按所有版本合起来判断，打开孩子的版本，不写次数。
- 家庭导出保持原来的格式和版本号，不变。
- 没有变化题的题和没有课堂内容的题只显示原题（最终答案）。
- 家长只在详情页上看到孩子在哪个版本上。
- 书上的 n / m 仍是「任何版本做完都算」。
- 旧版本的草稿照常在最后编辑 7 天后过期，选新版本时不删。
- 「这段时间」卡片的计数不变，不在这次的范围里。

写设计时补上的默认（维护者可以改）：

- 孩子做过的版本都已下架时，打开最新版本，不问。
- 孩子从别的链接打开另一个版本时，题目页换成孩子的版本的地址。
- 已下架的版本不知道流程，只显示原题。
- 「接着做原来的」不记录；选新版本只往上走，回不到旧版本。
- 家长的预览打开链接里的版本，不问。
