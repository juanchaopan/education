# 全站视觉改版：和题目页统一风格，减少提示文字

- 日期：2026-11-08
- 级别：L1 需求范围内的新功能；设计冲击 D1（先抽出公共界面部件，再换外观）
- 来源：维护者：“小朋友和家长的页面都太素、没有质感，提示性文字太多，和题目页风格完全不一样”；“不要像一个 AI 做的 test app，要全新设计。图标按钮、文字提示甚至动画，要像一个真正的产品走出来”；看过 #138 样稿后：“A、B 都有背景图片，不错。能不能 A 和 B 按照客户端当前时间来切换？自动切换。”

## 变了什么

之前网站页面是浅色底、细边框、文字链接和大段说明，每个页面各写一份按钮和卡片样式，和题目页的手作绘景完全不同。

之后网站用一套视觉语言：白天是手作工作台（暖色纸张、森林绿、黏土般的按钮），晚上是暮光剧场（深色夜景、暖金灯光），按设备本地时间自动切换；题目卡和横幅用绘景库里的图；图标、按钮、输入框、提示、空状态、加载和动效统一成公共部件；说明文字只保留做决定必须看的。

## 为什么

- 孩子从题库走进题目像换了一个网站；家长页面像测试工具，不像产品。
- 大段提示文字孩子读不完，家长也不读；需要的说明淹没在其中。
- 每个组件各写样式，改风格要逐个文件改，难以保持一致。

## 决定

- 定级 L1 + D1：先做一个外观不变的重构（#139），再换外观（#140），然后逐页改版。
- 先做探针画样稿（维护者要求），三个方向：手作工作台、暮光剧场、晨光绘本。
- 采用手作工作台和暮光剧场，按设备本地时间自动切换，6:00–18:00 为白天（维护者选定方向和自动切换，切换时刻按常见作息定）。
- 两套主题共用版式、字体、图标和动效，只换颜色、底纹和光晕。
- 图标自己画，标题用霞鹜文楷子集，网站图片先用绘景库里的图。
- 文字按设计文档的清单删减、改成控件或折叠，隐私、安全、不可撤回和授权的说明保留。
