# 家长总览：最近 7 天、学习时长和家庭时区

- 日期：2026-11-12
- 级别：L2 需求变更（REQ-005 的统计窗口和学习时长，REQ-002 和 REQ-011 的家庭时区，REQ-009 的保留和导出）；设计冲击 D1（加接口、表和页面上的部件，现有结构不用重做）
- 来源：[#164](https://github.com/juanchaopan/education/issues/164)；维护者 2026-11-12 的决定记在 [#164 的评论](https://github.com/juanchaopan/education/issues/164#issuecomment-6836609940)。

## 变了什么

之前 #164 计划给孩子卡片加「本周」（自然周）的统计、年级和柱状图，学习时长的计法、时区和年级由谁填都没有定。

之后：

- 卡片和柱子看**到昨天为止的最近 7 个完整日**，不用本周和自然周；今天的分钟数单独写一行。
- 柱高是每天的学习分钟。学习时长只在题目页可见、孩子 2 分钟内动过手时计时，每个孩子每天一个总数。
- 每个家庭有一个时区：注册时取家长浏览器的时区，家长可以改；它决定一天从几点开始，也决定家里页面白天和晚上主题的切换。
- 孩子账号**不加年级**。
- 数据保留到删除家庭；家长能在学习记录里一段一段往前翻；导出包括每一天的学习时长。

## 为什么

- 自然周到了周一就清零，周一早上看到的都是 0；到昨天为止的 7 天每天都有完整的一段可看。今天没过完，算进去会让最后一根柱子总是偏矮。
- 家长想知道孩子花了多少时间，题数说明不了这个；只在动手时计时，开着页面走开不会被算成学习。
- 一天从几点开始要按家庭所在的地方算，不能按服务器或某一台设备；主题也跟着家庭的钟走，家里几台设备看到的一样。
- 家长按书安排，书带着年级；孩子升级以后去年的书照样留着，账号上的年级没有用处。

## 决定

- 统计窗口是到昨天为止的 7 个完整日，今天单独写分钟；往前翻按首尾相接的 7 天一段，翻到最早有记录的一段。
- 道题按题目 id 数，同一道题的几个版本算一道；独立完成和提示后完成按次数，提示后完成不算独立完成；变化题的结果不进这些数。
- 学习时长由服务器按心跳的间隔算，间隔超过 90 秒的一段不算；断网时不算；上线以前的学习没有时长。
- 家庭时区存 IANA 名字；已有家庭在家长下次打开家长空间时取这台设备的时区，之前用 `DEFAULT_TIME_ZONE`（默认 `Asia/Shanghai`）。家长在「孩子」页的「家庭时区」卡片里修改，总览的设置列表多一行。
- 主题按家庭时区切换；这台设备没登录过家长或孩子时照旧看设备的钟。
- 不加年级。
- 学习时长保留到删除家庭；导出加家庭时区和每一天的学习时长。
