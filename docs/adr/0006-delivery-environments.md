# ADR-0006 交付环境与发布控制

- 状态：已接受（用户选择）；平台集成待验证
- 日期：2026-11-04
- 相关需求：REQ-007、009

## 背景与候选

试点需要验证家庭账号、儿童界面和迁移，不应将预览数据和生产数据混用。候选为单环境手工部署、PR CI 加隔离 staging 与手动生产、全自动 staging/标签生产流程。

## 决策

用户选择 PR CI、隔离 staging、平台支持时使用 PR 预览、显式手动生产发布。CI 执行锁文件安装、格式/lint/依赖边界、类型、单元与真实数据库接口测试、前端和 Storybook 构建、Playwright 关键流程与固定环境截图。按变更范围运行必要检查，不通过扩大跳过项制造通过。

部署保存精确提交标识，应用与配置可回退；数据库采用向后兼容迁移。生产前备份并检验可恢复性，不能将数据库端口暴露给公网。预览关闭后清理其环境与数据，绝不使用生产用户输入或密钥。大陆访问或供应商资格未通过时，只能标为测试环境，不宣称生产可用。

免费平台实际可用能力待验证；不因要求预览而擅自购买套餐。若使用用户服务器，先检查容量、TLS、数据库持久化、备份和网络，再配置发布。可通过 GitHub 生产环境审批或显式手动工作流控制发布，具体依据账号和仓库权限确定。

部署更新按 [ADR-0009](0009-account-security-spike.md) 提供一致构建标识与版本文件、入口重新验证和草稿保存后刷新；更新保留有效会话。生产仍需显式发布，不能将 git push 直接等同于已上线。实际缓存/浏览器和回滚测试由 #20/#33/#51/#52 和 [#118](https://github.com/juanchaopan/education/issues/118) 完成。

## 证据与后果

依据用户选择，无部署或 CI 运行证据。额外 staging/预览占用资源，可能因免费配额受限而采用短期测试环境；这一限制需明确报告。托管、邮件、监控、备份的实际凭据与平台配置是后续前提，不阻塞本地空框架开发。
