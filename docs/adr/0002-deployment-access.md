# ADR-0002 大陆访问与部署退路

- 状态：已接受（约束）；staging 选择见 ADR-0008，生产验证待完成
- 日期：2026-11-04
- 相关需求：REQ-003、007、008

## 背景与候选

免费托管可能存在访问、休眠、持久化、出口与配额问题。可选免费托管或用户自有服务器；域名不能代替服务器。

## 决策

用户确认大陆访问为硬条件。先核查免费候选；不满足时使用用户之后提供的自有服务器/域名。staging 的供应商选择由 [ADR-0008](0008-hosting-spike.md) 补充：采用 Vercel Hobby + 自定义域名，保留自有服务器退路。普通操作 2 秒、AI 开始有效响应 5 秒为健康态目标，10 秒未开始则提供引导模式选项，均从大陆实际设备测量。明确响应统计口径后再做验收。

## 证据

托管探针已完成 Vercel 独立 staging 部署、域名验证和证书配置，维护者报告测试成功；详见 [ADR-0008](0008-hosting-spike.md)。未提供地区/运营商或时延明细，完整产品、数据库及外部供应商调用仍待验证。官方文档及测试主机的云环境代理 403 不构成大陆可达性或供应商资格证据。

## 后果

需要验证前端、账号邮件、API、AI 全链路。OpenAI 出站连通性与服务条款资格必须分别验证。付费默认开启且节省 token；预算未确定，不能擅自创建付费基础设施。提供可移植部署和数据库备份恢复路径，实际服务器参数之后补充。
