# ADR-0016 网站视觉语言：两套主题按本地时间切换

- 状态：已接受。
- 需求：REQ-011。
- 关系：与 [ADR-0015](0015-lesson-kit-and-media-library.md) 的绘景库共用图片来源；题目画面的设计仍按 [ADR-0013](0013-per-problem-interactive-teaching.md)。

## 背景

题目页用电影感的手作绘景，网站其他页面是浅色细边框加大段说明，两边风格不一致，看起来像测试用的应用。#138 画了三个方向的样稿：A 手作工作台（暖色纸张、木质与黏土质感）、B 暮光剧场（深色夜景、暖金灯光）、C 晨光绘本（明亮的矢量插画，不用绘景）。维护者认为 A、B 都和题目页的绘景一致，要求按客户端当前时间自动切换。

## 决策

- **白天用 A，晚上用 B**：按设备本地时间，6:00–18:00 用手作工作台，其余时间用暮光剧场。首次渲染前决定主题，页面开着时到点平滑切换；切换时刻集中在一个配置常量里。题目画面不随主题变化。
- **两套主题只换颜色、底纹、阴影和光晕**，版式、字体、圆角、图标、动效相同，以免切换时页面跳动，也只需维护一套部件。
- **图标自己画**：24 格、2px 圆头描边的 SVG，放在 `shared/ui/icons`，不加图标库依赖，不用表情或符号代替图标。
- **标题字体用霞鹜文楷**（SIL OFL 1.1）：自托管并按用到的字子集化，不从境外字体服务加载；正文用系统黑体。
- **网站图片用绘景库里的图**（题目卡、首页横幅、登录页），第一版不另外生成；需要新插画时按 #135 的风格说明由 Codex ImageGen 生成。
- **文字从简**：口号和加载说明删除，格式说明交给控件，隐私、安全、不可撤回和授权的说明保留在做决定的那一步，次要细节折叠。逐条处理见设计文档。

## 被否决的方案

- **只用 A 或只用 B**：A 在夜里偏亮，B 在白天偏暗；维护者要求两者都用。
- **C 晨光绘本**：不用绘景，和题目页的手作质感不一致。
- **让家长手动选主题**：没有需求；令牌结构留有余地，以后需要时再加。
- **引入图标库**：现成图标库风格偏通用，题目相关的图标（青菜、尺子）仍要自己画；自己画一套更统一，也少一个依赖。
- **两套主题用不同字体**：切换时字宽变化会让版式跳动。

## 后果

- 页面和部件只引用令牌，任何写死的颜色都会让某一套主题出错，#140 要把它们全部换成令牌。
- 视觉基准要覆盖两套主题，测试用固定的模拟时间。
- 字体子集需要一个构建步骤；题目标题变化时子集要重新生成。
- 设计规格见 [网站视觉语言](../design/visual-language.md)，变更原因见 [变更记录](../changes/2026-11-08-visual-language.md)，样稿和截图见 [#138 记录](../evidence/138/README.md)。
