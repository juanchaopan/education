# #28 普通话语音与浏览器绘图探针证据

## Windows 桌面

Windows 11 Home 10.0.26200。Playwright 1.64.1 启动本机 Chrome 和 Edge，无头模式，390 × 844、DPR 3、模拟触摸。麦克风为浏览器合成媒体设备，页面隐藏由测试触发。每个浏览器测 5 次允许录音，另测拒绝、录音回放、隐藏时取消及画布操作。

| 检查                           | Chrome 156.0.8078.80                            | Edge 156.0.4314.58                             |
| ------------------------------ | ----------------------------------------------- | ---------------------------------------------- |
| 拒绝权限                       | `NotAllowedError`，仍可输入文字                 | `NotAllowedError`，仍可输入文字                |
| 允许后录音                     | 5/5 生成 WebM/Opus（380–2340 字节）；触发回放   | 5/5 生成 WebM/Opus（1060–2340 字节）；触发回放 |
| 点击录音到启动，P50 / 最大     | 67 / 276 ms                                     | 39 / 101 ms                                    |
| 点击结束到取得数据，P50 / 最大 | 6 / 11 ms                                       | 4 / 10 ms                                      |
| 隐藏页面                       | 取消录音、释放流、无录音回放、可重试            | 同左                                           |
| 设备端普通话检查               | 8 ms 返回 `downloadable`，未安装语言包          | 3 ms 返回 `unavailable`                        |
| 浏览器在线识别诊断             | 合成测试信号未产生文字，12 秒超时               | 合成测试信号未产生文字，4.64 秒结束            |
| 普通话朗读                     | 5 个语音选项，无本地普通话声音                  | 5 个语音选项，无本地普通话声音                 |
| 绘图                           | 模拟触摸落墨、`pointercancel`、鼠标及清空均通过 | 同左                                           |

合成麦克风信号用于媒体流程，未用于判断普通话识别准确率。回放事件只证明浏览器开始播放。两套浏览器均宣告支持 WebM/Opus 和 MP4；浏览器录制实测采用 WebM/Opus。最初 Edge 的空结果会覆盖已输入文字，修改后识别预览和答案分开，空结果不会改写答案。复测通过。

复测在线识别时使用同一合成普通话片段作为虚拟麦克风输入。Chrome 在 3.30 秒、Edge 在 3.71 秒结束，均未返回文字。该结果只覆盖当前配置与一个合成片段。

## 服务端转写

[GitHub Actions 42121265569](https://github.com/juanchaopan/education/actions/runs/42121265569)，Ubuntu 托管 runner、Node.js 24，直接调用 OpenAI 文件转写接口，使用 `gpt-transcribe` 和 `zh-cn` 语言提示。合成材料来自 eSpeak-NG `cmn`，用 FFmpeg 分别编码为 WebM/Opus 与 M4A/AAC。每条测试句每种格式各一次。先前的 [42120472583](https://github.com/juanchaopan/education/actions/runs/42120472583) 卡在安装工具，改用预先编码的样本。

| 预期短句                         | WebM 秒数 / 响应 ms | M4A 秒数 / 响应 ms |
| -------------------------------- | ------------------- | ------------------ |
| 我把十二平均分成三份，每份是四。 | 4.984 / 1680        | 4.976 / 1092       |
| 二十五减去七等于十八。           | 3.218 / 485         | 3.211 / 1252       |
| 我先画一个三角形，再画两个圆。   | 4.748 / 819         | 4.740 / 782        |

6/6 HTTP 200，识别语言均为 `zh`，文字及数字含义与预期一致。P50 956 ms、范围 485–1680 ms，从 runner 发出请求到读取完整 JSON，含请求传输，无目标部署或用户网络。按 US$0.0045/分钟估算，千次 5 秒录音约 US$0.375，千次 10 秒录音约 US$0.75。六个样本的时长约 25.88 秒，估算 US$0.00194。未用账单核对，也未测儿童语音、实际请求并发、配额或目标网络。Windows FFmpeg 解码三个 WebM 时报告 Opus 包头告警，命令均退出 0；服务接口仍完整识别了三条，正式接入需用真实浏览器产物回归。

## 原型修复与复测

识别和朗读控件现在就地显示正在启动、不可用、失败与停止状态。增加固定合成普通话录音，便于验证缺少本地声音时的回退。Chrome / Edge 无头复测通过预录音开始和停止（启动 116 / 184 ms）、画布外滚动、尺寸不变的 resize 保持像素、尺寸改变后重绘、清空后调整大小保持空白。HTTPS 音频范围请求返回 HTTP 206。浏览器事件记录不代表人工确认音质。

### iPhone 更新后复测

维护者更正首次使用 iPhone 版 Google Chrome；复测所用浏览器版本未从日志确认。复测时画布外滚动保留笔迹，设备端识别依然没有可见结果。预录的合成短句可听见，维护者认为声音吓人，淘汰为儿童产品声音。设备朗读曾提示无可用声音，后续点击报告开始朗读，维护者未听见声音。开始事件仅说明浏览器回报状态；本地朗读在该设备仍未通过可听性验证。预览将测试录音标为诊断用合成音，并显示系统报告的朗读状态。
