# #27 OpenAI 模型探针证据

## 实测结果

日期：2026-11-05。Node.js 24，GitHub 托管 Ubuntu runner，OpenAI Responses API 标准服务，`store: false`。每组并发运行三个候选配置，模型请求无自动重试。API 用量包括绘图输入。以下是 runner 到 API 的时延；没有部署到 Vercel，也没有测量大陆浏览器端到端时延。源码和图片均为合成测试夹具。

| 轮次 / 配置              | 完整响应 | 首个完整中文句子 P50 / P95（秒） | 每千次尝试费用（USD） | 质量观察                                                        |
| ------------------------ | -------: | -------------------------------: | --------------------: | --------------------------------------------------------------- |
| 1 / GPT-5.4 nano，无推理 |    12/12 |                      0.82 / 2.56 |                0.1269 | 位值题给了错误或容易误解的指示                                  |
| 1 / GPT-6 Luna，无推理   |    12/12 |                      1.07 / 2.09 |                0.0338 | 3/12 样本直接给出答案                                           |
| 1 / GPT-4.1 mini         |    12/12 |                      1.05 / 2.15 |                0.1113 | 三次位值题均给出答案，且模型已标记弃用                          |
| 2 / GPT-6 Luna，无推理   |    18/18 |                      1.00 / 2.46 |                0.0382 | 18/18 给出正确、可操作的提示或澄清，没有揭示最终答案            |
| 2 / GPT-6 Luna，低推理   |    13/18 |                      1.20 / 2.25 |                0.0547 | 5 次未完成，4 次用满 128 输出 token，另一次用量为零、原因未记录 |
| 2 / GPT-5.4 Mini，无推理 |    18/18 |                      1.00 / 2.18 |                0.3856 | 三次位值题仍揭示答案，遮挡图两次指示孩子查看错误位置            |

P50/P95 采用最近秩法，只统计带完整句子的成功响应；失败数分列。每组仅 12 或 18 次请求，P95 在此等于组内最大值。第二轮 Luna 无推理的 18 个样本均在 5 秒内给出首条可用提示，包括三次无答案泄露的位值提示、三次借十提示、三次请孩子移开遮挡物检查左边线段。遮挡物和缺口是不同的夹具。质量由人工检查合成输出，并非儿童真实教学验收。

按 API 返回的用量和公开标准价格计算，第二轮 Luna 无推理平均 196.5 输入 token、37 输出 token。文字 9 次约 US$0.0356/千次，绘图 9 次约 US$0.0407/千次，按本次一半文字、一半单张 256×192 绘图的组合约 US$0.0382/千次。实际图像大小、对话上下文和服务配置会影响账单。两轮记录有用量的测试约 US$0.0119；两次取消没有最终用量，未计入该估算。

第二轮取消样本在首个文字增量后于 561 ms 停止本地流读取，未收到最终用量；这不能证明服务商停止生成或免计费。未刻意耗尽额度，也未观测真实 429。正式后端收到超时、额度错误或缺少用量时应保留作答，转回题目专属引导，避免自动重试并在账本上保留待核对用量。产品设计仍需验证收到半句时如何丢弃结果。

**技术推荐**：`gpt-6-luna`，显式 `reasoning.effort: none`，流式 Responses API，先用第二轮的单句提示与 128 输出 token 上限作为试点参数。默认只发送当前题目步骤和必要输入。OpenAI 图像输入用于理解绘图，独立的生成图片端点未实测，也不是本轮教学反馈路径。维护者已接受该试点配置，见 [ADR-0011](../0011-openai-tutoring-model-spike.md)。
