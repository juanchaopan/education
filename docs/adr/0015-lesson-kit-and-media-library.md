# ADR-0015 课堂公共部件与共用的绘景库

- 状态：已接受。
- 需求：REQ-001、REQ-004、REQ-010。
- 关系：在 [ADR-0013](0013-per-problem-interactive-teaching.md) 的逐题设计上，确定 #48 共享候选的提取边界和绘景的来源。

## 背景

ADR-0013 让每道题独立编排场景，把共享候选留到多题验证后再提取。#48 的三道原型和 #49 正式接入的菜园题表明，片名卡和开始按钮、背景层、字幕和重听、可拖可点的道具、提示动画、逐句讲述和说完进下一幕，在每道题里都各写了一遍；正式代码里它们都写在菜园题自己的文件里，接下一道题就要整段复制。#129 的旁白缺陷也只能逐题修。每道题单独生成一张背景，生成次数多，风格不统一。

## 决策

- **公共部件放在网站的学习功能里**（`apps/web/src/features/learning`），不单独成包。部件包括逐句讲述和短片状态、旁白播放、拖动与点选、画面外壳、道具和提示动画、公共题目页、题目定义和登记表。现有分层检查照旧适用，另加一条：一道题的文件不能引用另一道题的文件。
- **一道题只写它独有的部分**：题目插件、台词和录音、分镜规则、道具画法、场景 SVG 和一份题目定义，在登记表里加一行上线。公共部件放不下时，先在公共部件里补（先重构、后加功能），再做这道题。
- **题目页全屏**：题目页不带网站导航和页脚，撑满屏幕；开始短片时请求浏览器全屏，不支持时只撑满。左上角的返回按钮回到孩子来时的题库，返回时退出全屏。
- **背景和讲课角色来自共用的库**：每张图带场景、时间色调、年龄段、空地形状和坐标、适合的题型等标签，新题按标签挑选；都不合适时按统一风格生成一张通用的新图入库。图片由 OpenAI 的图像生成制作，在 Codex 里用 ImageGen 生成，不调用付费 API；孩子能操作的对象写成 SVG。

每道题的分镜、数学对象、运动规则、教法与提示仍由题目决定，ADR-0013 的逐题验收标准不变。

## 后果

- 新题的页面代码不再复制；修一个公共部件，所有题目同时受益。
- 公共部件先只覆盖菜园题已有、三个原型都用到的部分；#125、#126 接入时检验，缺的部分先补公共部件。
- 背景库的图要中间留空地、不画角色和操作对象，构图比单题专用的背景通用；空地坐标记在清单里，题目的道具摆在空地里。
- 设计和迁移步骤见 [课堂公共部件与绘景库](../design/lesson-kit.md)，变更原因见 [变更记录](../changes/2026-11-08-lesson-kit.md)。
