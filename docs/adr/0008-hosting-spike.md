# ADR-0008 托管第一轮调研与自有服务器验证路径

- 状态：提议；等待维护者拍板，未选定生产平台
- 日期：2026-11-04
- 相关需求：REQ-007、REQ-009；相关任务：[#14](https://github.com/juanchaopan/education/issues/14)
- 约束：[ADR-0002](0002-deployment-access.md)、[ADR-0006](0006-delivery-environments.md)
- 证据：[来源、已执行检查与待测方案](assets/0014-hosting-evidence.md)

## 背景

试点为 10 家庭、约 3 名儿童同时学习，要求中国大陆手机、平板及桌面可访问。现有应用是 Node.js 24 / Fastify 同源提供 React 静态文件，数据库为 PostgreSQL；TypeScript 7 在构建阶段使用。免费额度必须同时考虑 API、数据库、隔离 staging 和预览，不能只比较静态网页托管。

本轮核实了 Railway、Neon、Cloudflare 的官方文档仓库。没有供应商账号、部署凭据、自有服务器信息或大陆测试设备；所有实际托管、容量和大陆网络指标均未测。Render 官网被本环境代理拒绝，未核实其当前套餐。结论是“尚无通过验证的免费完整方案”，不是“所有免费服务均不可用”。

追加验证：用户之后提供 Vercel 访问并要求继续测试。Vercel API 已确认 Hobby 工作区，独立 Node 24 / Fastify 探针在 `sin1` 的 staging 部署为 READY，本地浏览器检查通过。预览主机仍被当前工具环境的网络策略阻止，线上端点及大陆访问未测；数据库、完整应用与当前 Hobby 使用条款/额度尚未完成验证。详见[执行证据](assets/0014-hosting-evidence.md)。用户已选择先验证 Vercel，下面第一轮的自有服务器优先建议未被接受；正式平台决策仍为提议。

## 成本与可靠性判断

- Railway 文档 RAM 为 $10/GB/月。仅按假设的平均 0.125 GB 常驻内存计算，`0.125 × 10 = $1.25/月`，已超过 $1 免费额度，尚未算 CPU、数据库、流量和 staging。这是敏感性估算，不是本应用实测用量；短时启停仍可能落在免费额度内。Hobby 最低 $5/月，超额另计。[R2,R3]
- Neon 的 100 CU-hours 等于 0.25 CU 运行 400 小时；0.25 CU 全天运行 30 天为 180 CU-hours。3 个并发儿童不能直接换算用量，须测活跃时长、连接池、草稿大小和各环境的总消耗。数据库定时探活可能影响休眠，不能靠无限保活假装满足免费条件。[N1,N2]
- Neon 同一份 plans 文档的表格写 Free “Instant restore: Not available”，正文却写免费 6 小时 / 1 GB 历史；本轮不把 PITR 当作已确认能力。独立导出、恢复演练及删除清单仍由 #29、#45 落实。[N1,N5]
- 平台配额耗尽可能令整个应用或数据库停止服务。只有 AI 故障时继续引导，不意味着数据库或 API 停机时仍能保存进度。用户设置费用上限时须明确这种区别。[R10,N5]

## 提议决策

1. 保留可移植同源应用与 PostgreSQL，不因本轮调研改变架构。免费生产平台保持未决。
2. 优先收集自有服务器资料并做部署前验证；若维护者想先做免费云端实验，则用 Railway + Neon 创建仅含合成数据的短期 staging，记录明确的额度与清理时间。账号权限及免费资格确认后才能执行，不自动升级付费。
3. Cloudflare 只作为日后经过实测的可选交付组件；本轮不承诺 China Network 免费，也不认定全球免费网络被大陆阻断。Render 当前信息未核实，保留待查。
4. 只有真实大陆设备验证 HTML、所有本地静态资源、同源 API、服务端数据库路径及后续邮件/AI 流程后，才判断生产可用。第三方 AI 服务资格单独由 #27 验证，海外主机不是绕过限制的理由。

## 自有服务器所需资料

维护者之后提供以下非密钥信息即可安排下一轮；密码、SSH 私钥和供应商令牌通过受控凭据配置，不写聊天或仓库。

- 提供商与实际城市/区域，操作系统和 CPU 架构，vCPU / 内存、可用持久磁盘、带宽及流量限额；是否共用机器、是否允许 Docker，当前费用及可接受额外费用。
- 域名或可分配的 staging 子域名、DNS 管理方式、80/443 是否可用、证书签发与续期方式；若服务器在大陆，核实该域名和站点适用的备案/接入要求。
- 可用的受控管理连接、最小权限部署方式，镜像仓库拉取和软件源可达性；PG 不开放公网。
- 独立备份位置、容量和保留期，允许的数据损失/恢复时间（RPO/RTO），监控告警接收渠道；确定家庭删除后备份恢复不会使账号复活。
- 一台可参与验证的真实大陆设备及其省份、运营商、网络类型、浏览器版本；先选择候选 URL，再安排测量，不需要用户发送个人 IP。

域名本身不提供计算、数据库或备份；已有服务器也须验证，不默认达标。

## 后果与完成边界

本轮产出是带证据的候选筛选与下一轮方案，没有新增部署费用或正式应用代码。#14 在维护者确认结论、ADR 经独立文档 PR 落地前保持打开；Q-006 的大陆访问、托管选型和其他供应商问题继续未决。#15 的本地认证参数探针可独立推进；#20 的真实 staging 接入需要具体目标。

当维护者提供候选账号或自有服务器资料，或套餐/资源需求改变时重新评估。最终大陆端到端验收归 #51；本轮统计方案不替代用户确认的性能目标。
