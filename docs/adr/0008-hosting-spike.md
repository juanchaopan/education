# ADR-0008 Vercel Hobby 与自定义域名用于 staging

- 状态：已接受（维护者报告测试成功并要求结束 #14）；生产发布仍需后续验收
- 日期：2026-11-04
- 相关需求：REQ-007、REQ-009
- 任务：[#14](https://github.com/juanchaopan/education/issues/14)
- 约束：[ADR-0002](0002-deployment-access.md)、[ADR-0006](0006-delivery-environments.md)
- 证据：[验证记录及官方来源](assets/0014-hosting-evidence.md)

## 背景

10 家庭、约 3 名儿童同时学习的中文试点需要大陆访问、持久化进度、隔离 staging 和可移植部署。现有架构为 React / TypeScript 7、Node.js 24 / Fastify、PostgreSQL / Drizzle。免费静态页面可用不能单独证明账号、数据库、邮件与 AI 的完整链路可用。

维护者指定使用 `education-access-spike.hyp.app`，继续由 Vercel 托管。在完成 DNS、证书与 staging alias 配置后，维护者回复：“test successful. let's wrap up spike 14 commit push and pr”。这构成本轮探针的用户验收及结束授权。

## 决策

1. 采用 **Vercel Hobby + 自定义域名** 作为后续 staging 集成方向。已创建的 `education-access-spike` 只是独立网络探针；正式应用按 #20 重新集成，不合并或直接复制探针代码。
2. 当前测试域名由 **hyp DNS 面板**管理，CNAME 指向 Vercel，关闭 hyp 代理；Vercel 负责托管及证书。域名与托管分别管理，不因更换域名而推定大陆访问、服务器路径或第三方服务资格达标。
3. 保留 Node.js 24、Fastify、React、TypeScript 7 与 PostgreSQL 架构。Vercel 函数接入及正式 TS7 单仓构建须在 #20 验证；当前探针只验证同源静态文件与 Fastify 函数方向。Neon Free 是已调研的 PostgreSQL 候选，**未连接、未选定为正式数据库**。
4. 保留自有服务器退路。若套餐、持久化、资源或大陆访问不满足需求，使用维护者之后提供的服务器/域名资料验证迁移路径，不自动购买付费托管。
5. 继续执行 PR CI、隔离测试数据与密钥、显式手动生产发布。#14 的结论只解除 hosting 候选未定的阻塞，不替代 #51 的大陆完整链路与三儿童并发验收，也不替代 #52 的生产发布授权。

Render 官网在本环境遭代理拒绝，未读取当前套餐正文；不据此认定 Render 在大陆不可达。AI、邮件、域名注册和备份成本不自动包含在应用免费额度内。

成本敏感性示例：Railway 文档 RAM 为 $10/GB/月，仅假设平均 0.125 GB 常驻就为 $1.25/月，尚未计 CPU/DB/流量；这不是应用实测。Neon 0.25 CU 运行 30 天需 180 CU-hours，高于 100 免费 CU-hours；分支共用项目计算额度，不能直接用“3 名儿童”推定月度消耗。

Neon N1 表格称 Free Instant restore 不可用，正文却描述免费 6 小时 / 1 GB 历史；本轮不承诺免费 PITR。#29/#45 必须确定独立备份、恢复演练及删除清单。托管/数据库额度耗尽可能使应用停机，不能把 AI 引导降级当作数据库故障时仍能保存进度的保证。

## 证据与限制

- 本地 HTTP 与系统 Chromium 测试通过，包含页面资源、24 个请求（其中 20 个正式样本）、连续 503 时停止、POST 405、no-store。截图是本地移动布局，不是大陆线上截图。
- Vercel API 确认 Node 24、`sin1`、staging READY、域名 verified、CNAME 正确、证书存在及 alias 指向所需部署。
- 维护者明确报告测试成功；未提供 JSON、地区、运营商、设备或延迟明细。记录为**用户报告的功能测试成功**，不编造 P50/P95、冷启动时间、成功率，也不声称跨运营商或全大陆可达。
- 工具环境对预览域名及自定义域名的直接请求被本地代理 CONNECT 403 拒绝。该环境限制不等于 Vercel 故障；没有用云端出站代替大陆测量。
- 数据库、账号邮件、AI、语音、3 儿童并发、正式应用构建和长期配额未由此探针验证。

## 自有服务器退路所需资料

维护者之后提供非密钥信息：提供商/实际区域、OS/CPU 架构、vCPU/内存/持久磁盘、带宽和流量限额、共用负载与 Docker 条件、当前和可接受额外费用；域名/子域及 DNS 管理、80/443、TLS 签发续期方式；受控部署入口与镜像拉取能力；独立备份位置/保留期、RPO/RTO、监控渠道及大陆测试设备条件。大陆托管时核实适用备案/接入要求。密码和密钥只经安全配置，PG 不开放公网。

域名不能代替服务器。自有服务器同样须通过验证，迁移使用可移植应用构建和 PostgreSQL 导出/恢复，而非沿用未验证的供应商绑定。

## 归档与资源生命周期

探针代码归档为 [archive/spike-14-hosting-mainland](https://github.com/juanchaopan/education/tree/archive/spike-14-hosting-mainland)，正式分支只合入决策和证据。已删除两次中间部署；保留用户刚验收的无业务数据测试站 <https://education-access-spike.hyp.app/> 供复查，#20 接入正式 staging 时安排替换或退役。后续部署须重新确认 alias 目标，不能把测试域名默认当作产品生产域名。

重新评估条件：Hobby 条款/额度变化、正式应用无法满足函数或数据库约束、大陆实际网络失败、费用超出约定，或试点规模扩大。
