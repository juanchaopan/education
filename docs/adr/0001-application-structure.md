# ADR-0001 应用结构与技术方向

- 状态：已接受（用户选择）
- 日期：2026-11-04
- 相关需求：REQ-001 至 REQ-009

## 背景

最多 10 家庭与约 3 儿童同时学习，需要题目专属页面、账号隔离与后端 AI。大陆访问必须满足，免费平台失败可转用户服务器。

## 候选方案

| 方案                           | 优点                                 | 代价                                   |
| ------------------------------ | ------------------------------------ | -------------------------------------- |
| React 与 TypeScript 模块化单体 | 共享类型，低运维成本，适合交互式页面 | 需维护模块边界，应用共用发布周期       |
| React 与 Python API            | Python 生态丰富                      | 两套语言与协议维护                     |
| 微服务                         | 可独立扩展                           | 试点规模没有证据需要其部署和一致性成本 |

## 决策

用户已选择可移植模块化应用：Vite/React 前端，Fastify/TypeScript 后端，PostgreSQL/Drizzle 数据库，应用自管账号。同源单应用部署，保留业务模块边界。具体技术细节见 ADR-0003 和 ADR-0004；托管平台仍待验证。

## 证据与后果

依据用户回答和已确认规模，未做运行探针。采用技能包现有 React/Node 规范；可移植容器降低托管迁移成本，但不保证特定平台免费或大陆可达。并发或维护规模显著增加时重新评估。
