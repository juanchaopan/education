# ADR-0012 普通话语音与浏览器绘图的试点方案

- 状态：已接受，待正式接入和目标设备验收
- 日期：2026-11-05
- 相关需求：REQ-003、REQ-007、REQ-008
- 任务：[#28](https://github.com/juanchaopan/education/issues/28)

## 背景

儿童在手机、平板或桌面作答时，可以通过文字、语音或绘图表达。语音识别和朗读是独立能力。录音被拒绝、语音不可用或识别有误时，仍可用文字和题目交互。

## 候选方案

| 能力         | 试点方向                                | 取舍                                                                    |
| ------------ | --------------------------------------- | ----------------------------------------------------------------------- |
| 录音与转写   | 浏览器按需录音，服务端 `gpt-transcribe` | 已验证两种合成音频容器；有按时长计费和网络依赖                          |
| 浏览器识别   | 继续作为候选，按设备验证                | 桌面语言包可用性不同，浏览器在线处理路径也不同；部署不能只检测 API 对象 |
| 端侧开源识别 | Whisper WASM 暂缓                       | 无单次 API 费用；未量化平板耗时和内存，官方未量化的 tiny 权重约 75 MiB  |
| 朗读         | 经试听通过的普通话音频，始终展示文字    | 固定音频可重复播放；缺少合格音频时保留文字                              |
| 绘图         | Canvas + Pointer Events                 | 一套输入处理用于触摸和鼠标；需要实机回归指针取消、滚动与高 DPI          |

## 决策

维护者接受试点转写方案，并明确正式朗读需试听验收，可使用自然的 AI 声音。

[#41](https://github.com/juanchaopan/education/issues/41) 以浏览器 `MediaRecorder` 和可取消的服务端文件转写为试点起点。按设备检查支持格式，以实际录音 MIME 与容器为准。先用 WebM/Opus，按需使用 MP4/AAC。只在明确操作并经 [#37](https://github.com/juanchaopan/education/issues/37) 家长授权后录制短音频，停止录音后一次提交，取消或后台切换时释放音轨。后端遵守 [#39](https://github.com/juanchaopan/education/issues/39) 的时长、字节数、超时与用量约束。原始音频仅用于转写，应用默认不保存。识别结果单独预览、可纠正，确认后再提交；超时、拒绝、配额耗尽或无结果时保留文字草稿。浏览器在线识别需单独验证并经过相应的家长披露和授权。

[#42](https://github.com/juanchaopan/education/issues/42) 负责挑选和试听自然、清楚、适合儿童的普通话声音。维护者允许自然的 AI 声音，实际试听通过后才能给儿童使用。优先为固定指令生成一次并复用；始终显示文字，无合格音频时使用文字。停止、重播和切换步骤时取消上一次播放。淘汰探针的合成测试音；浏览器播放事件只记录诊断状态。[#32](https://github.com/juanchaopan/education/issues/32) 用同一画布处理触摸和鼠标；限制 `touch-action: none` 于绘图表面，支持指针捕获、取消、清空、画布外滚动与高 DPI。画布尺寸变化时从笔迹重绘。

## 证据

[浏览器矩阵、服务端测量及限制](assets/0028-browser-voice-touch-evidence.md)。Windows Chrome 和 Edge 的录音、权限及模拟触摸通过；服务端 6/6 返回正确的合成普通话转写，P50 0.96 秒、最大 1.68 秒。首次 iPhone Chrome 实测录音与回放成功，浏览器识别未出结果，设备朗读无声，滚动会清空笔迹。修复后 iPhone 复测保留笔迹，合成录音可听但音质被维护者否决，设备朗读报告启动但无可听声音。iPad 实机仍待验证。探针源码与合成夹具归档在 [archive/spike-28-browser-voice-touch](https://github.com/juanchaopan/education/tree/archive/spike-28-browser-voice-touch)。

## 后果

[#51](https://github.com/juanchaopan/education/issues/51) 从目标部署和大陆真实设备验证 iPad Safari 等未覆盖环境，记录媒体权限、格式、后台切换、普通话音质、触摸及端到端延迟。正式语音测试须覆盖真实作答的噪声、读数与措辞、配额、识别纠正和取消后迟到结果。
