# ADR-0013 逐题设计互动教学，按连续音画证据验收

- 状态：已接受作为正式设计与出课流程。#48 探针收尾。
- 需求：REQ-001、REQ-003、REQ-004、REQ-005。

## 决策

为每道题编排专属场景和启发顺序。开场先把题目在问什么讲清楚，再让孩子用手操作画面里的数学对象。保留前后关联，每次从一次可观察的变化推到一个新关系。高年级题把列式的每一项贴回对应的对象、长度或运动。最后给一题改变关键条件的练习，用理由与实际操作区分独立理解和跟着提示完成。

共享候选包括对象命中与直接拖动、音画进度、语义场景快照、帮助与恢复、证据采集。#31 在多题中验证候选边界后提取。每题的分镜、数学对象、运动规则、教法与提示由题目独立决定。#49 按正式流程接入真实题目。

Codex 与 Claude Code 从同一个仓库手册执行 `/change` 加 PDF。逐题交付实际浏览器预览、连续有声实录、冷启动审查、快慢与误操作记录、问题修改后的复验。实际录制、回看和独立理解分别记录。见[逐题设计与验收手册](../design/interactive-lesson-authoring.md)。

## 证据

两份样例均已逐题形成设计。三道本地原型验证了不同的场景操作。收尾保存[样例索引与验证记录](assets/0048-interactive-teaching-evidence.md)，原始题库、可执行探针和实录保留在本地。

- 菜园天平在同一秤上逐组替换，让等量关系可见。
- 彩铅用连线、收藏和逐排清点呈现无序配对。实录帮助发现并缩短红黄之后的等待，配对提示与相关旁白对齐。
- 数轴追及用同一组轨道、车辆、空隙和方向变化推导 (10-t) 与绝对值。实际浏览器快拖经过关键时刻仍会强制停住，最后一处停稳后有明确结束动作。

浏览器行为与录制证据支持上述交互判断。真人对完整旁白音色、节奏的判断，以及孩子能否独立举一反三，待正式验收。两工具共用一套标准，仍需在两边用同一份 PDF 分别实跑来验证一致性。

## 后续课堂语音联动

[#28 的语音输入](0012-browser-voice-touch-spike.md)已跑通录音和普通话转写，[#27 的 AI 提示](0011-openai-tutoring-model-spike.md)已实测模型调用。#48 原型使用预编排的语音和动画。后续复用这两条链路，验证孩子能否在讲解中开口，暂停于同一场景，让 AI 根据当前幕、对象和最近操作，用语音及经规则校验的场景动作解释，再回到原步骤。正式接入需处理家长授权、浏览器许可、误触发、降级及不保存原始音频。进题后的免逐次操作聆听仍需单独评估与现有按需录音约定的差异。

下一道语音联动候选为六年级讲义第 10 页的数轴折痕。孩子拖折痕观察镜像，问“为什么是四份”时，先高亮折前折后等长的五份，再在同一数轴上用其中一份说明剩下的四份。先验证这一问的实际语音与动画联动，再扩展开放追问。此题尚未实现。
