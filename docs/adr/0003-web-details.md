# ADR-0003 前端技术细节与视觉验证

- 状态：已接受（用户选择）
- 日期：2026-11-04
- 相关需求：REQ-001、003、004、005、006、007

## 背景与候选

主要是交互式学习与家庭管理，无已知 SEO 需求。比较 Vite 单页应用与 Next.js：前者可静态构建、迁移简单；后者适合服务端渲染，但增加服务端/客户端约束。比较自定义界面与大型 UI 库：自定义需要更多初期设计，更适合儿童触摸与耐心反馈。

## 决策

用户已选择 Vite、React Router、TanStack Query、CSS Modules 与设计令牌，页面/展示组件分层，Storybook 与 Playwright。服务器状态由数据访问 hooks 管理；展示组件不调 API。

用户已确认无 Redux/Zustand：题目内状态放最近的页面或交互控制器，跨路由的持久状态从后端恢复。用户已确认自定义组件，不加大型 UI 库；Vitest/Testing Library、ESLint/Prettier、dependency-cruiser 与 npm workspaces。此处不声明具体版本已安装或兼容。

## 证据与后果

依据用户明确选择，尚无代码或视觉基准。自定义界面增加设计工作；Storybook 和截图测试增加 CI 成本，但能评审空状态、重复指导、错误与触摸布局。真实浏览器的中文语音及大陆访问需另外验证。复杂共享交互状态出现时再评估状态库。
