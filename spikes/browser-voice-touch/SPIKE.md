# #28 浏览器普通话与绘图探针

## 问题

在可取得的 Windows 浏览器与 iPhone Safari 中，能否用浏览器能力可靠地录音、处理拒绝及中断、识别普通话、朗读中文并绘图？iPad 和其他缺少实机的设备单列。

## 一轮验证

- 录音：至少一次允许、拒绝和录制中切到后台。允许时产生可播放的非空数据，记录实际 MIME；拒绝和中断后能重试或输入文字。
- 识别：用固定短句“我把十二平均分成三份，每份是四”尝试三次，确认数字和运算含义，记录点击到最终结果的时间及错误。默认只检查设备端模式；系统在线识别需成人明确选择，可能由浏览器供应商处理。
- 朗读：播放固定短句三次，记录选择的中文语音及点击到 start 的时间，人工确认实际听到普通话；验证重播与停止。
- 绘图：画一条线、清空、在画布外滚动，记录指针类型和取消行为。自动输入单列为模拟。
- 只用成人或合成测试素材。页面没有账号、分析、上传或持久化；结果可手工分享。正式集成、儿童音频质量、长期配额和大陆端到端发布验收另行验证。

## 运行

在本目录运行 `node serve.mjs`，打开 http://localhost:8280/。手机需要 HTTPS 地址；此原型只包含 `index.html` 和 `probe.js` 两个可公开文件。
