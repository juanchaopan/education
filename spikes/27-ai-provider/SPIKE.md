## 问题与范围

哪家服务能够合法向大陆儿童提供中文推理和图像理解，适合 Vercel Singapore 后端与最多 10 家庭、约 3 名儿童并发的试点，并有可验证的费用和失败边界？

45 分钟主动调查时间盒，不将等待维护者配置或回传资料计入。维护者确认已有 OpenAI API 账号；未提供测试密钥。付费功能默认开启沿用既有需求，预算尚未确定；此次未创建任何付费资源或费用。

本轮不实现正式 AI 网关、家长同意页面、用量账本或教学页面，不修改 staging，不用真实儿童数据。语音录制、识别和朗读的设备验证属于 #28。生成图片不是本轮需求；这里的图像服务指理解孩子提交的图形。

## 成功与失败判据

1. 从厂商当前官方资料分别核实账号主体、部署地区、目标用户地区、未成年人及低龄儿童输入、数据保留/训练用途/删除、价格、限流与免费额度。保留文档 URL、读取时间、相关原文及适用套餐/区域；没有读取正文的条目不得标为通过。
2. 至少一个候选符合上述条件，才请求配置对应后端测试密钥。海外服务器、运营者在加拿大、有可用账号或一次 200 响应都不能代替目标用户资格。不同厂商/地区的条款和模型能力不可互相套用。
3. 对合格候选做合成中文文字与合成几何图的少量、预先计数调用。记录实际模型版本、后端区域、首次与预热请求、首个有用内容的耗时、最终响应与 usage、失败和取消情况。目标是健康时 5 秒内开始有效反馈，10 秒仍未开始则可继续引导；正式大陆全链路仍须 #51 实测。
4. 文档或凭据不足、目标用户不合格、费用不可界定、响应无法可靠解析，均记为阻塞。不会经第三方转发绕过厂商限制，也不会将本地模拟延迟当作厂商性能。

## 家长披露清单

选定前需要确定实际接收数据的服务商及处理地区、发送的文字/图像范围、用途、是否用于训练、供应商保留时长及例外、家长撤回方式、应用删除与供应商删除的边界。账号同意必须与未来服务商版本对应。默认不在本应用永久保存原始音频或绘图，不等于厂商零保留；取得家长同意不自动解决供应商地区或低龄使用限制。

## 费用计算与节省输入

[cost-planning.json](cost-planning.json) 是算术场景，不是实际使用预测或厂商报价。假设 10 家庭、每家庭 2 名孩子、每日每孩子 10 次调用、30 天，共 6,000 次：

| 文字场景           | 每次输入/输出 token（假设） | 每月输入/输出（百万 token） |
| ------------------ | --------------------------- | --------------------------- |
| 当前步骤和有限摘要 | 800 / 160                   | 4.8 / 0.96                  |
| 发送较长历史作比较 | 4,000 / 500                 | 24 / 3                      |

若输入价为 I、输出价为 O，单位均为同一币种/百万 token，两个文字场景分别为 `4.8I + 0.96O` 与 `24I + 3O`。尚无已核实的 I/O，不能给出真实月费。没有包含图片、音频、重试、税费、汇率或其他平台费用。

实际结算需按模型规则拆分未缓存/缓存输入、图片计量和输出；有些 reasoning token 已包含在输出 usage 中，不能重复加总。图片若已计入输入 token 就不能再重复按图片计费。免费赠额、缓存命中及批量折扣在资格和语义核实前不计入保守预算。

优先用题目规则，按明确提交调用；不逐笔发送画布，不持续传麦克风。只传当前步骤、必要摘要与可读的局部图，不附家长邮箱、家庭码、KEY、PIN、cookie 或持久儿童标识。输出长度上限不是总账单上限；失败或取消后 usage 缺失也不能记作免费。

## 合格后的最小调用计划（尚未执行）

先记录具体模型价格与最坏输入计量，提交有限调用总费用估算供维护者确认。初次最多 8 次正常请求（文字/图像各 1 次首次、3 次后续），不自动重试；取消及错误验证另外列明次数与最坏费用，再执行。这里的次数是测试提议，不是已批准的付费支出。

- 文字与图片使用独立的合成夹具，只在探针中使用，不加入正式题库；不冒充教育效果验收。
- 每次记录 DNS/连接之外的端到端开始时间、首个有意义的中文反馈时间、完整输出时间。SSE 心跳、空 delta、角色信息或内部推理不是有效反馈。
- 记录每次结果与样本数，首次/预热及文字/图像分开统计成功样本 P50/P95/max，同时列出失败率。8 次小样本只能排查明显问题，不能证明试点 SLA 或 3 儿童并发目标。
- 测试请求总期限与 10 秒引导切换分开。页面切换/主动取消应传播 AbortSignal，迟到内容不覆盖新操作。供应商可能已计费，取消不保证撤单或退款；最终 usage 缺失记为用量不确定。
- 输出 cap、上下文与图像尺寸在请求前校验；具体字段与模型支持能力以正式文档为准，不能把某模型字段套到所有兼容接口。
- 429/免费额度耗尽/余额不足时立即停止并继续引导，遵守 Retry-After，不自动开通付费、不无限重试。无配额可耗尽时只做本地故障注入，明确与真实供应商响应区分，不故意花光余额。
- 只保存安全的测量字段、请求关联 ID、模型版本和用量；不保存 Authorization、带鉴权的 URL、正文中的真实数据。测试 Key 仅后端使用，不放聊天、仓库、前端或日志。

运行/复核：这次只生成文档、公开 URL 的失败元数据和本地费用算术；不存在可运行的供应商适配器。后续真实调用须在文档可访问、资格已核实、测试密钥就绪和有限费用明确后另行编写临时探针。
